## 适用范围

本知识块依据 GB/T 3811—2008 第 6.1.2.7、6.2.1~6.2.4 及 6.3.4 节（剔除第 7 章电气及电动机相关条款），重点覆盖与金属结构支承反力及行走轮轨界面直接耦合的**车轮与轨道允许轮压校核（含工字钢梁下翼缘运行轨道）**、**运行防打滑黏着系数**及**通用机械零件静强度/稳定安全系数**。

## 1. 车轮与轨道允许轮压校核（6.3.4，式 130~133，表 46~49）

适用于直径 D ≤ 1000 mm 的车轮和滚轮；**既要按等效工作轮压校验踏面疲劳强度，也要按最大轮压（含静/动载试验工况）校验静强度**（6.3.4.2.1）。

### 计算轮压（6.3.4.2.2）

- **等效工作轮压（式 130）**：P_mean,Ⅰ/Ⅱ = (P_min,Ⅰ/Ⅱ + 2 · P_max,Ⅰ/Ⅱ) / 3（分别按无风载荷情况Ⅰ、有风载荷情况Ⅱ取空载最小轮压与满载最大轮压计算，取两者较大值；注意机械设计载荷按 4.4.2 含机构工作级别增大系数 γ'_m，表 21：M1=1.00 ~ M8=1.30）。
- **最大轮压 P_max（6.3.4.2.2.2）**：取载荷情况Ⅰ、Ⅱ、Ⅲ（**包括动载试验或静载试验工况**）中最不利状态和位置下的最大轮压。

### 轮轨有效接触宽度 l（6.3.4.2.2.3，图 14）

- **平顶钢轨（轨顶总宽 b、每边圆角半径 r）**：l = b - 2r
- **车轮在工字钢梁下翼缘上面运行（如悬挂式桥梁检查车在工字钢轨道下翼缘行走）**：
  - **有效接触宽度 l = w - r**（w 为车轮踏面宽度，r 为工字钢下翼缘外侧圆角半径；车轮直径 D 取投影宽度 (w - r) 中点处的直径！）
- 轨道材质提示（6.3.4.1.2 注）：采用普通型钢（如热轧工字钢、方钢、扁钢）作轨道时，应注意其材质与硬度低于专用钢轨（U71Mn / 55Q），必要时须降低许用轮压以保证足够寿命。

### 允许轮压与静强/疲劳校核（式 131~133）

- **踏面疲劳校核（式 131、式 132）**：P_mean ≤ P_L = k · D · l · C_1 · C_2
- **踏面静强度校核（式 133）**：P_max ≤ 1.9 · k · D · l（即静强取 C_max = 1.9）
- 注：对于具有凸起承压面的轨道或车轮，许用比压 k 可增加 10%。

## 2. 运行机构车轮防打滑黏着系数（6.1.2.7）

运行机构起动或制动时，须校验主动轮与轨道间不打滑，钢质车轮与钢轨之间的黏着系数（静摩擦系数）取值：
- **室内工作：0.14**
- **室外工作：0.12**

## 3. 通用机械零件静强度与稳定性安全系数（6.2.1~6.2.4，表 42，式 97~99）

适用于销轴支座、行走轮轴、传动轴、平衡台车铰轴等承载机械零件：
- 弹塑性材料（σ_s / σ_b < 0.7，式 97）：[σ] = σ_s / n_s
- 高强或热处理材料（σ_s / σ_b ≥ 0.7，式 98）：[σ] = σ_b / n_b（防止偶然过载发生脆断）

### 表 42 通用机械零件静强度安全系数 n_s 和 n_b

| 机械载荷情况（4.4.2） | 屈服安全系数 n_s | 抗拉强度安全系数 n_b（灰铸铁增加 25%） |
|---|---:|---:|
| 情况Ⅰ（无风正常）和情况Ⅱ（有风正常） | **1.48** | **2.2** |
| 情况Ⅲ（特殊载荷） | **1.22** | **1.8** |

### 危险点应力校核准则（6.2.3.2）

注意纯拉伸与拉弯复合中拉伸应力须乘 **1.25**：
- 纯拉伸：1.25 σ_t ≤ [σ]；纯压缩：σ_c ≤ [σ]；纯弯曲：σ_f ≤ [σ]；
- 拉弯复合：1.25 σ_t + σ_f ≤ [σ]；压弯复合：σ_c + σ_f ≤ [σ]；纯剪切：√3 τ ≤ [σ]；
- 拉弯剪复合：sqrt((1.25 σ_t + σ_f)² + 3τ²) ≤ [σ]；压弯剪复合：sqrt((σ_c + σ_f)² + 3τ²) ≤ [σ]。
- 易失稳机械零件按 5.6 校核并计入表 21 增大系数 γ'_m（6.2.4.1）；缓冲器允许最大减速度为 **4 m/s²**（6.3.5）。

## 回答限制与最小输入清单

校核轮压或行走机构承载零件时，必须确认：车轮直径 D、踏面宽度 w、轨道型式（平顶轨或工字钢下翼缘）及圆角 r、车轮与轨道抗拉强度、行走速度/转速、机构工作级别（M1~M8）以及空载/满载/试验工况下的最大最小轮压。
