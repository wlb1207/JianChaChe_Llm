# 结构刚性、容许长细比与静挠度校核

Source: GB/T 3811-2008
Topic: 结构刚性、容许长细比与主梁静挠度校核
SourceType: rule
Verified: true
Clause: 5.5, 表28
Page: 标准正文第42-44页

## 适用范围

本知识块依据 GB/T 3811—2008 第 5.5 节（5.5.1、5.5.2、5.5.3 及表 28），适用于起重机金属结构轴心受力杆件的容许长细比控制、桥架主梁跨中与悬臂端静态刚性（挠度）控制、大变形非线性分析提示及动态刚性原则。

- 刚性验算采用正常使用状态下的标准载荷；若按极限状态设计法，分项载荷系数取 γ_pi = 1（5.2.2.2.2）。
- 刚度合格不能替代强度、整体稳定、局部屈曲与疲劳校核；反之亦然。

## 轴心受力构件刚性与容许长细比（5.5.1，式 42、表 28）

轴心受力构件（如空间桁架上弦杆、下弦杆、斜腹杆、立柱及撑杆）必须满足式(42)：

- λ ≤ [λ]

实腹式构件对强轴 x 和弱轴 y 的长细比按式(43)计算：
- λ_x = l_cx / r_x，λ_y = l_cy / r_y，其中 r_x = sqrt(I_x / A)，r_y = sqrt(I_y / A)
- 计算长度 l_c 按附录 J（J.1，式 J.1~J.3）确定；等截面格构式组合构件采用换算长细比 λ_h（附录 J 表 J.5）。

### 表 28 结构构件的容许长细比 [λ]

| 构件类别 | 受拉结构件 [λ] | 受压结构件 [λ] |
|---|---:|---:|
| 主要承载结构件：对桁架的弦杆 | 180 | 150 |
| 主要承载结构件：对整个结构 | 200 | 180 |
| 次要承载结构件（如主桁架的其他杆件、辅助桁架的弦杆等） | 250 | 200 |
| 其他构件 | 350 | 300 |

> 工程提示：对于方管空间桁架结构（如桥梁检查车），**主桁架上弦杆、下弦杆属于主要承载桁架弦杆，受压长细比限值为 150、受拉为 180**；主桁架斜腹杆/立杆等其他杆件受压限值为 200、受拉为 250。减薄壁厚或减小截面外轮廓时，必须复核回转半径 r 变化后的长细比是否仍满足表 28。

## 桥架型起重机静态刚性推荐限值（5.5.2.1）

由**额定起升载荷**及**小车（或葫芦）自重载荷**在最不利位置产生的垂直静挠度推荐限值：

| 位置与驱动/控制特性 | 推荐垂直静挠度限值 | 说明 |
|---|---|---|
| 跨中：手动小车或手动葫芦（5.5.2.1.1.1） | f ≤ S / 400 | S 为起重机跨度 |
| 跨中：电动小车/葫芦，低定位精度，或无级调速控制，或低起升速度与低加速度达可接受定位精度（5.5.2.1.1.2） | f ≤ S / 500 | S 为起重机跨度 |
| 跨中：电动小车/葫芦，简单控制系统达中等定位精度 | f ≤ S / 750 | S 为起重机跨度 |
| 跨中：电动小车/葫芦，高定位精度 | f ≤ S / 1000 | S 为起重机跨度 |
| 有效悬臂长度位置：自行式小车或电动葫芦（5.5.2.1.2） | f_1 ≤ L_1 / 350 | L_1 为有效悬臂长度 |

## 其他起重机静刚性与大变形提示（5.5.2.2~5.5.2.4）

- 塔式起重机：额定起升载荷（含臂端小车自重）下，塔身顶部水平静位移推荐 ΔL ≤ 1.34 H / 100（H 为塔身自由高度）。
- 箱形伸缩式臂架轮胎/汽车起重机：变幅平面内臂端静位移推荐 f_L ≤ 0.1 (L_C / 100)²（L_C ≥ 45 m 时系数可适当增大）；附加 5% 额定载荷水平侧向力时回转平面侧向静位移推荐 Z_L ≤ 0.07 (L_C / 100)²。
- 5.5.2.4 规定：其他类型设备的静态刚性要求可由设计者或用户另行提出并在资料中说明；**当结构处于大变形状态时，位移宜采用几何非线性分析方法计算**。
- 注：对于悬挂式桥梁检查车，还应优先核对专用行业标准 **JT/T 1430—2022 表 3**（钢桁架跨中 `L/800`、悬臂端 `L'/400`）。

## 动态刚性（5.5.3）

- 对起重机的动态刚性一般不作强制要求；但当使用条件或设计认为影响操作平稳性、人员舒适性或振动控制时，应进行动态刚性校核（指标由设计者与用户约定，桥门式起重机可参见 ISO 22986:2007）。

## 预拱度、悬臂预翘与挠度评定注意事项（5.9.1.5）

- 对承载后产生较大弹性变形的主梁跨中应设向上预拱，悬臂段应设向上预翘（5.9.1.5）。
- 预拱度不能替代结构弹性刚度、强度或稳定校核；比对实测挠度与有限元弹性挠度时，必须明确是否已扣除预拱度与支承沉降。

## 回答限制与最小输入清单

判断刚度/长细比是否合格前，应确认：
- 构件长细比校核：构件类别（桁架弦杆/腹杆/整体）、拉压状态、几何长度、支承条件、截面惯性矩与面积；
- 静挠度校核：跨度 S 或有效悬臂长度 L_1、实测或仿真挠度值 f（及是否扣预拱）、驱动与定位精度要求、计算所加荷载工况（且检查车场景需对照 JT/T 1430—2022）。
