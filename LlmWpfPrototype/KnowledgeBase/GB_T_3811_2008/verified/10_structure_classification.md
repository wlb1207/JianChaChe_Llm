# 金属结构分类

Source: GB/T 3811-2008
Topic: 起重机金属结构分类
SourceType: rule
Verified: true
Clause: 5, 3, 附录G
Page: 标准正文约5-57页，附录G约140-172页

## 适用范围

本知识块用于识别起重机金属结构的构件类型、结构类别和计算关注点。

起重机金属结构通常包括主承载结构、辅助结构、连接结构和局部承压结构。不同结构件的计算项目和控制条件可能不同。

## 起重机主要金属结构

起重机常见主要金属结构包括：

- 主梁；
- 端梁；
- 小车架；
- 支腿；
- 下横梁；
- 起重臂；
- 塔身；
- 门架；
- 回转平台；
- 平衡臂；
- 运行机构支座；
- 司机室支承结构；
- 维修平台和走台；
- 栏杆、梯子和附属结构。

## 桥式起重机结构

桥式起重机通常包括：

- 主梁；
- 端梁；
- 小车架；
- 小车轨道；
- 大车运行机构支座；
- 走台和栏杆；
- 司机室支承；
- 电气设备支架。

桥式起重机主梁通常是最重要的承载构件之一，应重点校核：

- 强度；
- 刚度；
- 整体稳定；
- 局部稳定；
- 疲劳强度；
- 焊缝和连接强度；
- 轮压作用下腹板局部压应力。

## 门式起重机结构

门式起重机通常包括：

- 主梁；
- 支腿；
- 下横梁；
- 端梁；
- 小车架；
- 大车运行机构支座；
- 悬臂，若有；
- 门架连接节点；
- 走台和栏杆。

门式起重机除主梁外，还应重点关注：

- 支腿强度；
- 支腿稳定；
- 门架平面内和平面外稳定；
- 主梁与支腿连接；
- 下横梁与支腿连接；
- 风载荷；
- 抗倾覆；
- 防风锚定；
- 悬臂挠度。

## 臂架型起重机结构

臂架型起重机常见结构包括：

- 起重臂；
- 塔身；
- 门架；
- 回转平台；
- 平衡臂；
- 拉杆；
- 压杆；
- 转台连接结构；
- 支承结构。

臂架型结构通常应重点关注：

- 受压杆件整体稳定；
- 压弯构件稳定；
- 臂架平面内和平面外稳定；
- 风载荷；
- 回转惯性载荷；
- 抗倾覆；
- 节点连接强度；
- 疲劳强度。

## 箱形梁结构

箱形梁是起重机主梁常用结构形式。

箱形梁通常由以下板件组成：

- 上翼缘板；
- 下翼缘板；
- 腹板；
- 横隔板；
- 加劲肋；
- 端部连接板；
- 轨道垫板或轨道梁。

箱形梁应重点校核：

- 上、下翼缘弯曲正应力；
- 腹板剪应力；
- 腹板局部压应力；
- 复合应力；
- 腹板局部稳定；
- 翼缘板局部稳定；
- 加劲肋构造；
- 焊缝强度；
- 疲劳细节。

## 工字形梁结构

工字形梁可用于轻中型起重机主梁、轨道梁或辅助梁。

工字形梁应关注：

- 弯曲强度；
- 剪切强度；
- 侧向整体稳定；
- 腹板局部稳定；
- 翼缘局部稳定；
- 焊缝或轧制型钢截面质量；
- 小车轮压或葫芦轮压引起的局部应力。

## 桁架结构

桁架结构常用于臂架、门架、轻型主梁或支承结构。

桁架结构应重点校核：

- 杆件轴向拉压强度；
- 受压杆件稳定；
- 节点板强度；
- 焊缝或螺栓连接强度；
- 平面外稳定；
- 局部构造刚度；
- 疲劳强度；
- 风载荷。

## 板件和壳体结构

起重机金属结构中常见板件和壳体包括：

- 箱形梁腹板；
- 箱形梁翼缘板；
- 支腿壁板；
- 圆筒结构；
- 塔身板件；
- 回转平台板件；
- 节点板；
- 连接板。

板件和壳体应按受力状态进行局部稳定或屈曲校核。

## 连接结构

起重机金属结构连接形式包括：

- 焊接连接；
- 普通螺栓连接；
- 高强度螺栓连接；
- 销轴连接；
- 铆接连接；
- 法兰连接；
- 拼接板连接。

连接结构应根据实际受力校核：

- 拉压强度；
- 剪切强度；
- 承压强度；
- 抗滑移能力；
- 焊缝有效截面；
- 孔边承压；
- 疲劳强度；
- 局部构造强度。

## 结构分类与计算项目的关系

不同结构分类对应不同计算重点：

| 结构类型 | 常见控制项目 |
|---|---|
| 主梁 | 强度、刚度、稳定、疲劳、局部压应力 |
| 支腿 | 强度、稳定、风载、连接 |
| 端梁 | 强度、轮压、连接、疲劳 |
| 小车架 | 强度、刚度、疲劳、连接 |
| 臂架 | 压弯稳定、整体稳定、风载、疲劳 |
| 桁架杆件 | 轴力强度、压杆稳定、节点连接 |
| 箱形梁板件 | 局部稳定、加劲肋、复合应力 |
| 焊缝连接 | 静强度、疲劳、焊缝质量 |
| 螺栓连接 | 剪切、拉伸、承压、抗滑移 |

## RAG回答限制

如果用户询问某个结构件如何校核，必须先确认：

- 起重机类型；
- 结构件名称；
- 结构形式；
- 材料牌号；
- 受力类型；
- 计算目的；
- 是否承受循环载荷；
- 是否承受风载；
- 是否有局部轮压；
- 连接形式。

不得在未确认结构类别和受力状态时直接给出单一校核公式。
