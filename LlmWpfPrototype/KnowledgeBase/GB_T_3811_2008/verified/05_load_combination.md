## 适用范围

本知识块依据 GB/T 3811—2008 第 4.1~4.3 节、表 10~表 20 以及附录 D、E、G.4、H，用于确定起重机及类桥门式金属结构静力计算与有限元仿真（ANSYS APDL）的加载边界条件、动载系数、风载荷与工况组合。

## 1. 三类载荷情况与 18 种载荷组合（4.3.2、4.3.3、表 20）

GB/T 3811—2008 明确将金属结构计算分为三类基本载荷情况：

| 载荷情况 | 含义 | 包含子组合 | 许用应力法安全系数 n | 是否含风载荷 |
|---|---|---|---|---|
| **载荷组合 A** | **无风工作情况**（常规载荷） | A1（起升离地）、A2（空中突然卸载）、A3（悬吊运动加减速）、A4（不平轨/路运行） | **1.48** | **不含风载荷** |
| **载荷组合 B** | **有风工作情况**（常规 + 偶然载荷） | B1~B4（对应 A1~A4 + 工作风载/雪冰/温差）、B5（坡道不平轨恒速偏斜运行 + 工作风载） | **1.34** | **含工作风载 P_WⅡ** |
| **载荷组合 C** | **特殊载荷工作或非工作情况** | C1（最大速度猛烈起升 φ2max）、C2（非工作状态 + 非工作风载 P_WⅢ）、C3（动载试验 φ6 + 试验风载）、C4（缓冲碰撞 φ7）、C5（倾翻水平力 P_SL）、C6（意外停机 φ5）、C7（机构失效 φ5）、C8（基础外部激励/地震）、C9（安装拆卸运输） | **1.22** | C2 含非工作风载 P_WⅢ；C3 含试验风载 |

> 重要纠偏：**载荷组合 A 为无风工作情况，不包含工作状态风载荷**；疲劳校核通常仅按载荷组合 A（A1~A4）计算（4.3.4.2.6、5.8.1）。

## 2. 常规载荷与动力系数（4.2.1）

1. **自重振动载荷 φ_1 · P_G**（4.2.1.1.3）：
   - φ_1 = 1 ± α，0 ≤ α ≤ 0.1（桥式和门式起重机按表 G.13 取 α = 0.1，即 0.9 或 1.1，取最不利方向）。
2. **起升动载荷 φ_2 · P_Q**（4.2.1.1.4，表 10、表 11、式 7）：
   - φ_2 = φ_2min + β_2 · v_q（一般起重机 φ_2max ≤ 2.0，塔机/港口臂架 ≤ 2.2）
   - 起升状态级别表 10：HC1（平稳，β_2=0.17，φ_2min=1.05）、HC2（轻微冲击，0.34 / 1.10）、HC3（中度冲击，0.51 / 1.15）、HC4（较大冲击，0.68 / 1.20）。
   - 稳定起升速度 v_q 按驱动方式（表 11）：H1 常速取 v_qmax；H2/H3 低速控制取 v_qmin；H4 无级变速取 0.5 v_qmax；H5 预紧自动加速取 0。
3. **突然卸载冲击系数 φ_3**（4.2.1.1.5，式 8）：
   - φ_3 = 1 - (Δm / m) · (1 + β_3)（抓斗 β_3 = 0.5；电磁盘 β_3 = 1.0）。
4. **运行冲击系数 φ_4**（4.2.1.1.6，式 9）：
   - 轨道焊接且接头打磨光滑的高速轨道起重机：φ_4 = 1.0；
   - 轨道接头存在高低差 h（mm）时，按式(9)：φ_4 = 1.1 + 0.058 · v_y · sqrt(h)（v_y 为运行速度 m/s）。
5. **驱动加（减）速动载系数 φ_5 与水平惯性力**（4.2.1.2，表 12、表 13）：
   - 表 12：回转离心力 1.0；无间隙无级变速平稳变化 1.2；微小间隙一般控制 1.5；明显间隙突变 2.0；大间隙/严重反向冲击 3.0。
   - 起重机或小车水平运行起制动惯性力按质量×加速度×φ_5（一般取 φ_5 = 1.5），且不大于主动轮与轨道黏着力；高加速度全轮驱动时取驱动轮压的 1/30 ~ 1/4。

## 3. 偶然载荷：风载荷、偏斜侧向力、坡道与温度（4.2.2、附录 D、附录 E）

### 风压与风载荷公式（4.2.2.3、4.2.3.1，式 10~15）

- 计算风压（式 10）：p = 0.625 v_s²（N/m²，v_s 为离地 10 m 处 3 s 阵风风速 m/s；工作态阵风为 10 min 平均风速的 1.5 倍，非工作态为 1.4 倍）。
- 工作状态风载荷（式 11、12）：垂直吹风 P_WⅡ = C · p_Ⅱ · A（不计高度变化）；斜向吹风乘 sin²θ；吊运物品风载荷 P_WQⅡ = 1.2 p_Ⅱ A_Q（式 13）。
- 非工作状态风载荷（式 15）：P_WⅢ = C · K_h · p_Ⅲ · A（需计高度变化系数 K_h，且仍悬吊的吊具按 ηm 计风载）。

### 表 15 与表 18 计算风压与风速速查

| 状态与地区 | 计算风压（N/m²） | 对应 3 s 计算风速 v_s（m/s） | 备注 |
|---|---:|---:|---|
| 工作态 p_Ⅱ：内陆一般风力 | 150 | 15.5 | 正常风压 p_Ⅰ = 0.6 p_Ⅱ |
| 工作态 p_Ⅱ：沿海、台湾及南海诸岛 | 250 | 20.0 | 距海岸线 100 km 内 |

### 风力系数 C 与双片桁架挡风折减系数 η（表 16、表 17）

- **表 16 风力系数 C**：
  - 单片直边型钢平面桁架结构：**C = 1.70**；
  - 单根轧制型钢、矩形空心型材（方管）、钢板：随空气动力长细比 l/b 从 ≤5 到 ≥50，**C = 1.30 / 1.35 / 1.60 / 1.65 / 1.70 / 1.90**；
  - 管材制成的三角形截面空间桁架（附录 E.2）：侧向风力系数 **C = 1.3**；
  - 大箱形截面（>350 mm 方管或 250×450 矩形）：b/d = 1 时 C = 1.40~1.90。
- **表 17 两片平行等高相同桁架的挡风折减系数 η**（用于后片桁架迎风面积折减，总有效迎风面积 A = (1 + η) · φ · A_0；n 片等距平行按式 14）：
  - 间隔比 a/b = 0.5：充实率 φ = 0.1~0.6 对应 η = 0.75 / 0.40 / 0.32 / 0.21 / 0.15 / 0.10；
  - 间隔比 a/b = 1.0：φ = 0.1~0.6 对应 η = 0.92 / 0.75 / 0.59 / 0.43 / 0.25 / 0.10；
  - 间隔比 a/b = 2.0：φ = 0.1~0.6 对应 η = 0.95 / 0.80 / 0.63 / 0.50 / 0.33 / 0.20；
  - 间隔比 a/b = 4.0：φ = 0.1~0.6 对应 η = 1.00 / 0.88 / 0.76 / 0.66 / 0.55 / 0.45；
  - 间隔比 a/b ≥ 6.0：无遮挡，η = 1.00。

### 偏斜运行水平侧向载荷与坡道/走台载荷（4.2.2.1、4.2.2.2、4.2.4.2、附录 D）

- **偏斜水平侧向载荷（式 D.1）**：P_S = 0.5 · (ΣP) · λ，其中 ΣP 为受侧向力一侧端梁有效轴距内车轮静最大轮压之和（不计动力系数），λ 按跨度与有效轴距之比 S/B（或 S/a）查图 D.2。
- **坡道载荷（4.2.2.2）**：轨道式起重机轨道坡度 **≤ 0.5%** 时不考虑坡道载荷，超过 0.5% 按实际坡度计算重力分量。
- **走台、平台与通道局部载荷（4.2.4.2）**：仅作用于局部部位及直接支承构件——**堆放物料处 3000 N，仅作走台或通道处 1500 N**（注：9.3.2.4 另规定平台表面承受 2000 N/φ125 圆盘及 4500 N/m² 均布载荷不发生永久变形）。

## 4. 特殊载荷要点（4.2.3）

- **缓冲碰撞载荷（4.2.3.2）**：水平运行速度 **v_y ≤ 0.7 m/s 时，作用在起重机结构上的缓冲碰撞力可不考虑**；v_y > 0.7 m/s 时乘弹性效应系数 φ_7（弹簧等线性缓冲器 φ_7 = 1.25，液压等矩形缓冲器 φ_7 = 1.6）。
- **试验载荷（4.2.3.4）**：静载 1.25 P，动载 1.1 P × φ_6，φ_6 = 0.5 (1 + φ_2)，试验风速 ≤ 8.3 m/s。

## 5. 桥式和门式起重机专项组合与极限状态系数（附录 G.4、附录 H）

- 许用应力设计法按**表 G.11**（安全系数 A=1.48、B=1.34、C=1.22，高危险度系数 γ_n = 1.05~1.10）。
- 极限状态设计法按**表 G.12**（抗力系数 γ_m = 1.10）：
  - 自重振动/运行冲击：γ_pA = 1.16，γ_pB = 1.05，γ_pC = 1.05；
  - 起升载荷：γ_pA = 1.34，γ_pB = 1.22，γ_pC = 1.10；
  - 驱动加速力：γ_pA = 1.55，γ_pB = 1.41，γ_pC = 1.28；
  - 工作风载：γ_pB = 1.10，γ_pC = 1.05；偏斜侧向力 γ_pB = 1.10；
  - 非工作风载/试验载荷：γ_pC = 1.10；碰撞/倾翻/意外停机/机构失效：γ_pC = 1.28。

## 回答限制与最小输入清单

确定载荷组合前必须确认：设备类型、室内或室外及地区（内陆/沿海）、计算目的（静强度、刚度、稳定、疲劳或抗倾覆）、设计方法（许用应力法或极限状态法）与当前工况（正常/有风/试验/非工作暴风）。
