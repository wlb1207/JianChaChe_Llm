# 主梁与悬臂垂直静挠度要求

Source: GB/T 3811-2008
Topic: 挠度要求
SourceType: rule
Verified: true
Clause: 5.5.2, 5.5.3, 5.2.2.2.2, 5.9.1.5
Page: 标准正文第34、43-44、57页

## 适用范围

本知识块依据 GB/T 3811—2008 第 5.5.2、5.5.3、5.2.2.2.2 及 5.9.1.5 节，专门用于桥架主梁跨中静挠度、有效悬臂端静挠度、大变形非线性位移与预拱度的工程判定。

## 1. 桥架型起重机跨中与悬臂垂直静挠度限值（5.5.2.1）

由**额定起升载荷**及**小车（或葫芦）自重载荷**共同作用在最不利位置产生的垂直静挠度推荐限值：

### 跨中位置（5.5.2.1.1，S 为起重机跨度）

- **手动小车或手动葫芦**：f ≤ S / 400
- **自行式小车或电动葫芦——低定位精度，或具有无级调速控制特性，或采用低起升速度和低加速度达可接受定位精度**：f ≤ S / 500
- **自行式小车或电动葫芦——使用简单控制系统达到中等定位精度**：f ≤ S / 750
- **自行式小车或电动葫芦——高定位精度要求**：f ≤ S / 1000

### 有效悬臂长度位置（5.5.2.1.2，L_1 为有效悬臂长度）

- **自行式小车或电动葫芦位于有效悬臂位置**：f_1 ≤ L_1 / 350

## 2. 其他典型结构静位移限值（5.5.2.2、5.5.2.3）

- 塔式起重机：额定起升载荷（及臂端小车自重）下，塔身连接处水平静位移推荐 ΔL ≤ 1.34 H / 100（H 为塔身自由高度）。
- 箱形伸缩臂流动式起重机：变幅平面臂端静位移推荐 f_L ≤ 0.1 (L_C / 100)²；加 5% 额定载荷水平侧向力时回转平面侧向静位移推荐 Z_L ≤ 0.07 (L_C / 100)²。

## 3. 挠度计算载荷、非线性分析与预拱度规定

- **标准值加载（5.2.2.2.2）**：刚性验算采用正常使用状态的标准载荷（极限状态法分项载荷系数 γ_pi = 1），不采用强度校核的极端偶然或试验超载工况。
- **大变形非线性分析（5.5.2.4）**：当结构处于大变形状态时，位移宜采用几何非线性分析方法计算。
- **动态刚性（5.5.3）**：一般不强制要求；对平稳性、防振或舒适性有要求时，由设计者与用户约定指标（桥门式可参见 ISO 22986:2007）。
- **跨中预拱与悬臂预翘（5.9.1.5）**：承载后弹性变形较大的主梁跨中应设向上预拱、悬臂段应设向上预翘，且宜由构造或下料保证。预拱度不改变结构弹性刚度，验收对比时须明确实测值是否已扣除预拱与支承沉降。
- **桥梁检查车专项对照**：对于悬挂式桥梁检查车，应同时严格对照专用标准 **JT/T 1430—2022 表 3**（钢桁架跨中 `L/800`、悬臂端 `L'/400`，比 GB/T 3811 悬臂推荐值 `L_1/350` 更严格）。

## 回答限制与最小输入清单

判断挠度是否合格前必须确认：跨度 S 或有效悬臂长度 L_1、计算或实测挠度值 f（及是否已扣除预拱）、小车/驱动与定位精度类型、加载工况（是否仅含额定载荷与小车自重）以及设备是否还须满足专用行业标准（如 JT/T 1430—2022）。
