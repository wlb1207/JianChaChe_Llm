# 整机抗倾覆稳定性与轨道抗风防滑安全性

Source: GB/T 3811-2008
Topic: 抗倾覆与抗风防滑安全性
SourceType: rule
Verified: true
Clause: 8.1, 8.2, 表51-表55, 式142-式145
Page: 标准正文第102-110页

## 适用范围

本知识块依据 GB/T 3811—2008 第 8 章（8.1 整体抗倾覆稳定性、8.2 抗风防滑安全性，表 51~表 55，式 142~式 145），适用于室外及轨道运行起重机（含门式、桥式、悬臂式、悬挂轨道检修车类参考校核）在工作状态与非工作状态下的抗倾覆与抗风防滑移安全验算。

## 1. 整体抗倾覆稳定性基本原则（8.1.1）

- 判定准则：**稳定力矩代数和 > 倾覆力矩代数和**（均对最不利特定倾覆线计算；由自重载荷产生稳定力矩，由其余载荷产生倾覆力矩，**不另计动力系数 φ_i**）。
- 假定基础/轨道坚实水平；在斜面上工作时须计入轨道坡度影响；有地震要求时须按抗震设防等级叠加外部激励。
- **大变形影响（8.1.3.8、8.1.4.5）**：对因载荷、风载产生显著弹性变形的结构（如大悬臂桁架或细长塔身，二阶变形使弯矩增加 ≥ 10% 或 N/N_E ≥ 0.1），抗倾覆与抗后倾覆计算**必须计及大变形（二阶效应）**导致的力臂增大！

## 2. 除流动式、塔式和浮式以外的起重机抗倾覆载荷（8.1.4，表 54）

适用于门式起重机、悬臂桥架及各类轨道式起重结构：

| 校验工况 | 作用载荷 | 风载荷 | 惯性力 | 说明 |
|---|---|---|---|---|
| **Ⅰ. 基本稳定性** | 1.5 P_Q | 0 | 0 | 无风静载抗倾覆，P_Q 含永久性附件 |
| **Ⅱ. 动态稳定性** | 1.3 P_Q | P_WⅡ（工作风） | P_D（驱动惯性力） | 最不利风向与加减速方向叠加 |
| **Ⅲ. 非工作最大风** | 0 | 1.2 P_WⅢ（非工作风） | 0 | 暴风停机状态 |
| **Ⅳ. 突然卸载** | -0.2 P_Ⅰ | P_WⅡ（工作风） | 0 | P_Ⅰ 为有效载荷（不含永久附件） |

### 工作状态抗后倾覆稳定性（8.1.4.1）

当设备卸载且所有可移动部件缩回最靠近后倾覆线位置时：
- **力矩法（8.1.4.1.1）**：由工作风载 P_WⅡ 与惯性力 P_D 构成的倾覆力矩 **≤ 稳定力矩的 90%**；
- **重力法（8.1.4.1.2）**：不计风载时，静止整机质心在水平面上的投影距前支点距离 **≤ 前支点至后倾覆线距离的 80%**。

> 注：流动式起重机抗倾覆按表 51/52（1.25 P_Q + 0.1 F 等，后倾覆轻载侧支承力 ≥ 15% 总重）；塔式起重机按表 53（基本 1.6 P_Q、动态 1.35 P_Q + P_WⅡ + P_D、后倾覆 -0.2 P_Q + P_WⅡ、暴风 1.2 P_WⅢ、装拆 1.25 P_a + P'_WⅡ + P_D）。

## 3. 轨道式起重机抗风防滑安全性（8.2.1，式 142、式 143、表 55）

适用于除塔式起重机以外的露天轨道式起重机（轨道塔机见式 144、式 145，风载系数为 1.2）：

### 正常工作状态（带载、顺风、下坡运行制动，式 142）

- P_Z1 ≥ 1.1 P_WⅡ + P_α + P_D - P_f

其中：
- P_Z1：运行机构制动器在车轮踏面上产生的制动力（N），**但不得超过被制动车轮与轨道的黏着力（轮压 × f）**；
- P_WⅡ：工作状态最大风载荷（4.2.2.3.3）；
- P_α：自重与额定载荷沿坡道下滑分力；
- P_D：停车减速惯性力（取 φ_5 = 1）；
- P_f：运行摩擦阻力，P_f = ω · (P_Q + P_G)。

### 非工作状态（暴风停机，式 143）

- P_Z2 ≥ 1.1 P_WⅢ + P_αG - P_f

其中：
- P_Z2：制动器与夹轨器、锚定装置或防风拉索产生的沿轨抗风防滑阻力（夹轨器单独作用时 P_Z2 = P · f；制动轮侧受黏着力上限约束）；
- P_WⅢ：非工作状态风载荷（式 15）；
- P_αG：自重沿坡道下滑分力；
- P_f：非工作态被制动车轮与轨道黏着摩擦阻力，P_f = P_G · f（对被制动轮）；
- 手工操作夹轨器时，手动最大操作力不得大于 **200 N**。

### 表 55 运行摩擦阻力系数 ω 和静摩擦系数 f

| 系数类型 | 工况/摩擦副 | 取值 |
|---|---|---:|
| 运行摩擦阻力系数 ω | 装滑动轴承的车轮 | **0.015** |
| 运行摩擦阻力系数 ω | 装减摩（滚动）轴承的车轮 | **0.006** |
| 静摩擦系数 f | 轨道与制动车轮之间 | **0.14** |
| 静摩擦系数 f | 轨道与夹轨钳之间 | **0.25** |

## 回答限制与最小输入清单

进行抗倾覆与抗风防滑计算前必须确认：设备类型与支承/轨距布置、整机自重与重心坐标、额定载荷及最不利悬臂位置、工作风压 p_Ⅱ 与非工作风压 p_Ⅲ、迎风面积与风载作用点高度、轨道坡度、制动轮数量与夹轨/锚定装置额定夹持力，以及大悬臂结构是否已计入二阶弹性变形。
