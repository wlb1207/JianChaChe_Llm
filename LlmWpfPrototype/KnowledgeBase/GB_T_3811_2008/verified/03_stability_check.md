## 适用范围

本知识块依据 GB/T 3811—2008 第 5.6 节、第 5.7 节及附录 J、K、L、M、N，适用于起重机及桁架/箱形金属结构的轴心受压稳定、受弯整体稳定、压弯构件稳定、格构构件稳定、薄板与加劲板局部屈曲以及圆柱壳局部屈曲校核。

## 1. 轴心受压构件整体稳定性（5.6.1、表 29、附录 J、附录 K）

### 假想长细比（式 44、式 45）

当钢材屈服点 σ_s > 235 N/mm² 时（如 Q345 / Q355），需换算为假想长细比后查稳定系数 φ：
- 实腹式构件：λ_F = λ · sqrt(σ_s / 235)
- 格构式构件：λ_hF = λ_h · sqrt(σ_s / 235)

### 整体稳定校核公式（式 46）

- N / (φ · A) ≤ [σ]

其中 φ 根据假想长细比 λ_F（或 λ_hF）和表 29 截面类别，查附录 K 表 K.1~K.4（或按表 K.5 解析公式计算）：
- 正则长细比 λ_n = (λ / π) · sqrt(σ_s / E)，E = 2.06×10⁵ N/mm²
- 当 λ_n ≤ 0.215：φ = 1 - α_1 · λ_n²
- 当 λ_n > 0.215：φ = [ (α_2 + α_3 λ_n + λ_n²) - sqrt((α_2 + α_3 λ_n + λ_n²)² - 4 λ_n²) ] / (2 λ_n²)

### 表 29 常见轴心受压截面分类与表 K.5 系数

| 截面类型（板厚 t < 40 mm 常见情况） | 对 x 轴 | 对 y 轴 | 备注 |

| 轧制圆管 / 焊接圆管（t<40） | a 类 / b 类 | a 类 / b 类 | 轧制工字 b/h≤0.8 为 x:a、y:b |

### 计算长度系数与格构构件（附录 J、5.6.1.3）

- 等截面受压构件计算长度 l_c = μ_1 · l（表 J.1：两端铰支 μ_1 = 1.0；一端固接一端自由 μ_1 = 2.0；一端固接一端铰支 μ_1 = 0.70；两端固接 μ_1 = 0.50）。变截面乘 μ_2，有拉臂钢丝绳乘 μ_3。
- 格构式构件换算长细比 λ_h（表 J.5）：
  - 双肢缀板：λ_hy = sqrt(λ_y² + λ_1²)，**缀板单肢长细比 λ_1 不应大于 40**；缀板纵向宽度 ≥ 2/3 肢距，厚度 ≥ 肢距/40 且 ≥ 6 mm；
  - 双肢缀条：λ_hy = sqrt(λ_y² + 27 A / A_1)；四肢矩形缀条：λ_hx = sqrt(λ_x² + 40 A / A_1x)；**斜缀条与构件轴线倾角应在 40°~70° 之间**。
- 格构构件横截面剪力（式 47）：Q = (A [σ] / 85)·sqrt(σ_s/235) 或 Q = (N / (85 φ))·sqrt(σ_s/235)。
- 单面连接单角钢压杆按式(46)计算时许用应力折减系数：等边角钢 0.6 + 0.0015λ（≤1.0）；短边相连不等边 0.5 + 0.0025λ（≤1.0）；长边相连 0.70（5.6.1.2.2）。

## 2. 受弯构件整体稳定性（5.6.2、附录 L）

### 免算整体稳定性条件（5.6.2.1）

满足下列之一时，受弯构件可不必验算侧向弯扭整体稳定性：
1. 有刚性较强的走台和铺板与受压翼缘牢固相连，能阻止侧向位移；
2. **箱形截面受弯构件 h / b ≤ 3**（h 为截面高，b 为两腹板外侧间翼缘宽），或构件截面足以保证侧向刚性（**如空间桁架**）；
3. 两端简支且端部不扭转的等截面轧制 H 型钢或焊接工字梁，受压翼缘侧向支承间距 l 与宽 b 满足：
   - 无侧向支承、载荷作用在受压翼缘：l / b ≤ 13 · sqrt(235 / σ_s)
   - 无侧向支承、载荷作用在受拉翼缘：l / b ≤ 20 · sqrt(235 / σ_s)
   - 跨中受压翼缘有侧向支承：l / b ≤ 16 · sqrt(235 / σ_s)

### 整体稳定校核公式（5.6.2.2，式 48、式 49）

- 单向受弯：M_x / (φ_b · W_x) ≤ [σ]
- 双向受弯（轧制 H / 焊接工字）：M_x / (φ_b · W_x) + M_y / W_y ≤ [σ]
- 侧向屈曲稳定系数 φ_b 按附录 L（式 L.1、表 L.1~L.3）确定；φ_b > 0.8 时按式(L.2)修正 φ'_b = φ_b² / (φ_b² + 0.16)。

## 3. 压弯构件整体稳定性（5.6.3、附录 M）

### 简便计算公式（5.6.3.1）

定义名义欧拉临界力：N_Ex = π² E A / λ_x²，N_Ey = π² E A / λ_y²（E = 2.06×10⁵ N/mm²）。

- 当 N / N_Ex < 0.1 且 N / N_Ey < 0.1（一阶近似，式 50）：
  N / (φ A) + M_x / W_x + M_y / W_y ≤ [σ]
- 当 N / N_Ex ≥ 0.1 或 N / N_Ey ≥ 0.1（计入二阶 P-Δ 放大效应，式 51）：
  N / (φ A) + [1 / (1 - N/N_Ex)] · (M_x / W_x) + [1 / (1 - N/N_Ey)] · (M_y / W_y) ≤ [σ]
- 弯扭屈曲稳定性（式 52）：
  N / (φ A) + [1 / (1 - N/N_Ex)] · [M_x / (φ_b W_x)] ≤ [σ]

> 极限状态设计法变更（5.2.2.2.4）：放大系数中的 N_E 亦须除以抗力系数 γ_m = 1.10。

### 精细计算与仿真要求（5.6.3.2、附录 M）

- 附录 M 提供了考虑修正系数 ψ、端弯矩折减系数 C_o（≥0.4）与横向载荷系数 C_h 的更详细公式（式 M.1~M.5）。
- **M.1.2 规定：对空间格构式构件，除整体稳定外，还应将其受压弦杆及受压腹杆视为轴心压杆，分别验算单肢稳定性**。
- **M.5 制造误差附加弯矩**：可将初始变形 f_0 或磨损间隙位移 f'_0 引起的附加弯矩 N·f_0 加入端弯矩项（此时第一项 φψ 取 1）。
- **5.6.3.2 明确允许采用非线性有限元分析**直接求解压弯大变形与失稳行为。

## 4. 薄板与壳体局部屈曲（5.7、表 30、附录 N）

### 板的临界应力与欧拉应力（5.7.1.1~5.7.1.3，式 53~60）

- 四边简支单向均匀受压板欧拉应力：σ_E = [π² E / (12(1 - μ²))] · (t / b)² = 18.62 · (100 t / b)²（E = 2.06×10⁵ N/mm²，μ = 0.3）
- 单项弹性临界应力：σ_i,1cr = χ K_σ σ_E；τ_i,cr = χ K_τ σ_E；σ_i,mcr = χ K_m σ_E
- 弹性嵌固系数 χ：受压翼缘有扭转约束的工字梁和**箱形截面梁腹板，受弯取 χ = 1.64、受剪取 χ = 1.23**；无扭转约束单腹板工字梁受弯取 χ = 1.38；其他板件一般取 χ = 1.0。
- 屈曲系数 K_σ、K_τ、K_m 按附录 N 表 N.1（区格板，如均压 ψ=1 且 α≥1 时 K_σ = 4.0；纯弯 ψ=-1 且 α≥2/3 时 K_σ = 23.9；纯剪 α≥1 时 K_τ = 5.34 + 4/α²）与表 N.2（带肋板）计算。
- 复合应力临界值 σ_i,ccr 按式(56)合成；**当 σ_i,ccr > 0.8 σ_s 时，按式(57)及表 30 弹塑性折减**：σ_cr = σ_s [1 - 1 / (1 + 6.25 m²)] = ρ σ_s（m = σ_i,ccr / σ_s；m=0.8→ρ=0.80，m=1.0→ρ=0.86，m=1.5→ρ=0.93，m=2.0→ρ=0.96）。
- 局部稳定许用应力：[σ_cr] = σ_i,ccr / n（≤0.8σ_s）或 σ_cr / n（>0.8σ_s），其中局部稳定安全系数 n 取表 22 强度安全系数（1.48 / 1.34 / 1.22）。
- 局部稳定校核（式 60）：sqrt(σ_1² + σ_m² - σ_1 σ_m + 3τ²) ≤ [σ_cr]。

### 均匀受压翼缘板免算局部稳定条件（5.7.1.4）

同时满足下列宽厚比且板中计算压应力 ≤ 0.8 [σ] 时，可不必验算局部稳定：
- 工字形截面受压翼缘自由外伸宽厚比：≤ 15 · sqrt(235 / σ_s)
- **箱形构件两腹板之间（或符合 5.7.1.5.2 的纵肋之间）受压翼缘宽厚比：≤ 60 · sqrt(235 / σ_s)**

### 加劲肋构造尺寸要求（5.7.1.5，式 61~67）

- 横向加劲肋间距 a：对纯弯（ψ = -1）腹板，一般 0.5 b ≤ a ≤ 2 b；成对矩形横肋 b_s ≥ b/30 + 40（mm），t_s ≥ (b_s / 15)·sqrt(σ_s / 235)（单侧配置时 b_s 放大 1.2 倍）；非矩形横肋惯性矩 I_s1 ≥ 3 b t³。
- 腹板纵肋（ψ = -1）：a/b ≤ 0.85 时 I_s2 ≥ 1.5 b t³；a/b > 0.85 时 I_s2 ≥ (2.5 - 0.45 a/b)(a/b)² b t³。
- 均匀受压翼缘等距纵肋：惯性矩 I_s3 按式(66)/(67)校核。

### 圆柱壳局部屈曲（5.7.2，式 68~71）

- 当薄壁圆柱壳 t / R ≤ 25 σ_s / E 时应验算局部稳定：临界应力 σ_c,cr = 0.2 E (t / R)（超过 0.8σ_s 按式 57 折减），校核 N/A + M/W ≤ σ_c,cr / n。
- 长度 > 10R 时应设中间加劲环（间距 ≤ 10R），惯性矩 I_s4 ≥ (R t³ / 2)·sqrt(R/t)。

## 回答限制与最小输入清单

进行稳定与屈曲判断前必须确认：构件类型（实腹/格构/箱形/薄板/壳体）、材料 σ_s、几何长度与两主轴支承条件、截面尺寸与宽厚比、加劲肋布置、载荷组合与轴力/弯矩/剪力数值。
