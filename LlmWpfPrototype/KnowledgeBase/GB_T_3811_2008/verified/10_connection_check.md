# 金属结构连接强度校核（焊缝、螺栓与销轴）

Source: GB/T 3811-2008
Topic: 连接强度校核
SourceType: rule
Verified: true

## 适用范围

本知识块依据 GB/T 3811—2008 第 5.3.2、5.4.1.4、5.4.2 节（表 23~表 27、式 35~式 41），用于起重机及桁架金属结构的对接焊缝、角焊缝、普通螺栓、摩擦型高强度螺栓、承压型高强度螺栓及销轴连接的静强度校核。

> 注意：主要承载结构在同一连接处不宜混合使用不同的连接方式（5.9.1.7）；承受反复循环载荷（E4 级及以上）的连接还须按第 5.8 节表 32 与附录 O 进行疲劳校核。

## 1. 焊缝连接强度计算（5.4.2.1、表 23、式 36、式 37）

### 焊缝材料与质量分级（5.3.2.1、5.3.2.3.1）

- 焊条/焊丝/焊剂须与母材综合机械性能匹配（GB/T 5117、GB/T 5118、GB/T 5293、GB/T 8110）；坡口符合 GB/T 985、GB/T 986；质量分级按 GB/T 19418。
- 表 23 焊缝静强度许用应力（[σ] 为母材基本许用应力）：
  - **对接焊缝 B 级、C 级**：拉压 [σ_h] = [σ]，剪切 [τ_h] = [σ] / √2；
  - **对接焊缝 D 级**：拉压 [σ_h] = 0.8 [σ]，剪切 [τ_h] = 0.8 [σ] / √2；
  - **角焊缝（自动焊、手工焊）**：剪切 [τ_h] = [σ] / √2。

### 对接焊缝计算（5.4.2.1.1）

- 按连接中**最薄板厚 t** 计算；无引弧板施焊时，每条焊缝计算长度 = 实际长度 - 2t。
- 轴向拉压：σ ≤ [σ_h]；弯剪联合：危险点 σ ≤ [σ_h] 且 τ ≤ [τ_h]。
- 复合应力校核（式 36、式 37，注意对接焊缝剪应力系数为 **2** 而非母材的 3）：
  - 单向正应力 + 剪应力（式 36）：sqrt(σ² + 2 τ²) ≤ [σ_h]
  - 双向正应力 + 剪应力（式 37）：sqrt(σ_x² + σ_y² - σ_x σ_y + 2 τ_xy²) ≤ [σ_h]

### 角焊缝计算（5.4.2.1.2）

- 按抗剪强度计算，**有效计算高度一般取 0.7 h_f**（h_f 为较小焊脚尺寸）。
- 侧向角焊缝计算长度 = 实际长度 - 2 h_f（自身闭合焊缝或端部采取避免凹弧措施时可不减 2 h_f）；最大计算长度限值见 5.9.2.2.3（动载 40 h_f、静载 60 h_f，最小 8 h_f）。
- 受复合内力（轴力、剪力、弯矩、扭矩）时，先分别求出各内力单独引起的应力，再按**矢量和**合成总应力，校核 τ_合 ≤ [τ_h] = [σ] / √2。

## 2. 普通螺栓与销轴连接（5.3.2.2、5.3.2.3.2、5.4.2.2.1、表 25）

- **C 级普通螺栓**：孔壁间隙大，**只允许用于受拉连接或安装临时固定，不得用于承受动载荷的主要受力结构**（5.4.2.2.1、5.9.3.5）。
- **A、B 级普通螺栓**：可用于受动载荷结构，须分别校验螺杆抗拉（0.8 σ_SP / n）、抗剪（单剪 0.6 σ_SP / n、双剪 0.8 σ_SP / n）及板件孔壁承压（1.8 [σ]；C 级螺栓承压为 1.4 [σ]）。直接受动载的受拉普通螺栓须设双螺母或有效防松措施（5.9.3.6）。
- **销轴连接（5.3.2.2、表 25）**：主要承载销轴宜选用 45 钢、40Cr、35CrMo、42CrMo 并适当热处理；校核销轴弯曲 ≤ [σ]、销轴剪切 ≤ 0.6 [σ]、耳板/连接构件承压 ≤ 1.4 [σ]（有微动时承压许用应力适当降低）。

## 3. 高强度螺栓连接（5.4.1.4、5.4.2.2.2、表 26、表 27、式 35、式 38~41）

- **承压型高强螺栓（5.4.2.2.2.2）**：不适用于直接承受动载荷或连接处有反向内力的结构，起重机承载结构一般不采用。
- **摩擦型高强螺栓受剪（式 38）**：单个螺栓许用剪力 [P] = (Z_m · μ · P_g) / n
  - Z_m：传力摩擦面数；μ：抗滑移系数（表 26：Q345 及以上喷砂 0.55、无机富锌漆 0.40、钢丝刷干净表面 0.35；Q235 分别为 0.45、0.35、0.30）；P_g：预拉力（表 27，按 0.7 σ_sl · A_l，如 10.9S M20 为 155 kN、M24 为 223 kN）；n：表 22 安全系数。
- **摩擦型高强螺栓受拉（式 39）**：单个螺栓轴向许用拉力 [P_t] ≤ (0.2 σ_sl · A_l) / (1000 n β)，且不宜大于 1.0 P_g。
  - 载荷分配系数 β（L 为连接板总厚，d 为公称直径）：L/d ≥ 3 时 β = (0.26 - 0.026 L/d) + 0.15；L/d < 3 时 β = (0.17 - 0.057 L/d) + 0.33。
- **摩擦型拉剪联合（5.4.2.2.2.1 c）**：式(38)中以 (P_g - 1.25 P_t) 替代 P_g，且外拉力 P_t ≤ 0.7 P_g。
- **螺栓数目与拧紧力矩（式 40、式 41）**：Z = N / [P]（受剪）或 N / [P_t]（受拉）；施工拧紧力矩估算 M = K · d · P_g（kN·m，d 单位为 m；皂化/磷化处理 K = 0.11~0.15，未处理 K = 0.15~0.20）。
- **摩擦型高强螺栓连接构件净截面强度（5.4.1.4，式 35）**：N' / A_j ≤ [σ]，其中 N' = N · (1 - 0.5 Z_1 / Z)（Z_1 为最外列螺栓数，Z 为接头一侧总螺栓数，A_j 为净截面积）。

## 回答限制与最小输入清单

评定连接是否合格前必须确认：连接形式（对接焊/角焊/普通螺栓/摩擦型高强螺栓/销轴）、母材牌号与板厚、焊缝质量分级与焊脚/有效长度（或螺栓等级、规格、数量、摩擦面处理与孔径）、载荷组合（A/B/C）、设计内力（轴力、剪力、弯矩、扭矩）以及是否需要疲劳校核。
