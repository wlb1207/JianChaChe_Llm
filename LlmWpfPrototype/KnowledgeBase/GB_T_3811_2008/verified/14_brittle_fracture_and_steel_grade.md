## 适用范围

本知识块依据 GB/T 3811—2008 第 5.3.1.1 节与附录 I（表 I.1、表 I.2、式 I.1~式 I.7），用于评价起重机与桥梁检查车钢结构在低温、厚板及焊缝残余拉应力联合作用下的脆性破坏风险，并确定所需钢材质量等级（A、B、C、D 级与冲击功要求）。

> 规范强调（附录 I 引言）：仅完成抗屈服、抗失稳、抗疲劳计算，仍不足以证明钢材具备足够的抗脆性破坏安全性；须按残余应力、板厚与最低工作环境温度综合评价选择钢材质量组别。

## 1. 沸腾钢禁用条件与环境温度取值（5.3.1.1）

下列承载结构与构件**不应采用沸腾钢**：
- 焊接结构：
  1. 直接承受动载荷且需要计算疲劳的结构；
  2. 虽可不计算疲劳，但工作环境温度 **< -20 ℃** 时直接承受动载荷的结构，以及受拉、受弯的重要承载结构；
  3. 工作环境温度 **≤ -30 ℃** 的所有承载结构。
- 非焊接结构：工作环境温度 **≤ -20 ℃** 且直接承受动载荷并需计算疲劳的结构。
- 室外结构工作环境温度 T（5.3.1.1.3）：用户未特别指定时，取使用地点的**年最低日平均温度**。

## 2. 影响脆性破坏三因素评价系数（附录 I.1）

### 因素一：纵向残余拉应力与自重拉应力联合作用系数 Z_A（式 I.1~I.3）

按构件焊缝汇聚程度划分三类焊缝（σ_G 为永久载荷 γ_p=1 引起的纵向拉应力；若钢材屈强比 σ_s/σ_b ≥ 0.7，式中 σ_s 以 0.5σ_s + 0.35σ_b 代之）：
- **Ⅰ 类焊缝**（无焊缝或仅有横向焊缝，危险性小）：仅当 σ_G / σ_s > 0.3 时计入，Z_A = σ_G / (0.3 σ_s) - 1；
- **Ⅱ 类焊缝**（仅有纵向焊缝，危险性增加）：Z_A = σ_G / (0.3 σ_s)；
- **Ⅲ 类焊缝**（焊缝汇聚、高度应力集中，危险性最大）：Z_A = σ_G / (0.3 σ_s) + 1（若对 Ⅲ 类焊缝进行 600~650 ℃ 消应力热处理，可按 Ⅰ 类焊缝选取）。

### 因素二：材料厚度影响评价系数 Z_B（式 I.4、式 I.5）

- 当 5 mm ≤ t ≤ 20 mm：Z_B = (9 / 2500) · t²（例如 t = 5 mm 时 Z_B = 0.09；t = 10 mm 时 Z_B = 0.36；t = 20 mm 时 Z_B = 1.44）；
- 当 20 mm < t ≤ 100 mm：Z_B = sqrt(0.65 t - 14.81) - 0.05。
- 轧制型材/实心矩形截面采用假想厚度 t'：圆截面 t' = d / 1.8；方截面 t' = t / 1.8；矩形截面（长边 b、短边 d）：b/d ≤ 1.8 时 t' = b / 1.8，b/d > 1.8 时 t' = d。

### 因素三：工作环境温度影响评价系数 Z_C（式 I.6、式 I.7）

当工作环境温度 T < 0 ℃ 时计入（T ≥ 0 ℃ 时 Z_C = 0）：
- 当 -30 ℃ ≤ T < 0 ℃：Z_C = (6 / 1600) · T²（例如 T = -10 ℃ 时 Z_C = 0.375；T = -20 ℃ 时 Z_C = 1.50；T = -30 ℃ 时 Z_C = 3.375）；
- 当 -55 ℃ < T < -30 ℃：Z_C = (-2.25 T - 33.75) / 10。

## 3. 总评价系数与钢材质量组别确定（表 I.1、表 I.2）

计算总评价系数 ΣZ = Z_A + Z_B + Z_C，查表 I.1 与表 I.2 确定所需钢材质量组别与冲击功要求：

| 总评价系数 ΣZ | 钢材质量组别 | 冲击功 A_KV（J） | 冲击试验温度（℃） | 对应钢材牌号 |
|---|---|---:|---:|---|
| ΣZ ≤ 2 | 组别 1 | — | — | Q235A、Q345A、Q390A |
| 2 < ΣZ ≤ 4 | 组别 2 | Q235 ≥ 27；低合金钢 ≥ 34 | +20 | **Q235B、Q345B（现 Q355B）、Q390B** |
| 4 < ΣZ ≤ 8 | 组别 3 | Q235 ≥ 27；低合金钢 ≥ 34 | 0 | Q235C、Q345C（现 Q355C）、Q390C、Q420C、Q460C |
| 8 < ΣZ ≤ 16 | 组别 4 | Q235 ≥ 27；低合金钢 ≥ 34 | -20 | Q235D、Q345D（现 Q355D）、Q390D、Q420D、Q460D |

> 工程提示：高寒地区（如东北、西北年最低日平均温度低于 -20 ℃）的露天桥梁检查车焊接桁架，当节点存在 Ⅲ 类汇聚焊缝且 T = -25 ℃~-30 ℃ 时，ΣZ 极易超过 4，此时原 Q355B（+20 ℃ 冲击）可能不满足抗脆断要求，需升级为 **Q355C（0 ℃）或 Q355D（-20 ℃）**。

## 回答限制与最小输入清单

评定钢材质量等级（B/C/D 级）前必须确认：使用地区最低日平均环境温度 T、构件板厚 t、焊缝汇聚类别（Ⅰ/Ⅱ/Ⅲ 类）及自重永久载荷引起的纵向拉应力 σ_G。
