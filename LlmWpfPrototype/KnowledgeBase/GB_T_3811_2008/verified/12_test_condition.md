# 试验载荷工况与结构验收复核

Topic: 试验工况与验收校核
SourceType: rule
Verified: true

## 适用范围

本知识块依据 GB/T 3811—2008 第 4.2.3.4 节、第 4.3.3.3 节（载荷组合 C3）、表 20 以及附录 G.4（表 G.11、表 G.12），用于起重机及桥梁检查车类金属结构在静载试验、动载试验及结构有限元复核中的载荷取值与边界约束。

## 1. 试验环境与通用条件（4.2.3.4）

- 起重机投入使用前应进行静载试验和动载试验。
- 试验场地应坚实、平整。
- **试验时风速不应大于 8.3 m/s**（对应表 E.1 约 4 级风、计算风压 43 N/m²）。

## 2. 静载试验载荷（4.2.3.4.1）

- 加载方式：整机静止不动，静载试验载荷作用于起重机**最不利位置**，且应**平稳无冲击**地加载。
- 载荷标准值（除订货合同或专用产品标准另有更高要求外）：**1.25 P**
  - 对流动式起重机：P 为有效起重量与可分及固定吊具质量总和的重力；
  - 对其他起重机：P 为额定起重量的重力（不包括作为起重机固有部分的吊具质量）。
- 专用行业对照：对于悬挂式桥梁检查车，须特别注意 **JT/T 1430—2022 第 7.2 节**规定——检查车静载试验采用 **1.5 倍额定载荷**（持荷 10 min，3 次加载卸载后主结构无永久变形与裂纹），动载试验采用 **1.25 倍额定载荷**！按 4.2.3.4.3.2 规定：**若专用产品标准或合同规定的试验载荷高于 1.25 P / 1.1 P，结构承载能力必须按实际更高试验载荷值验算**。

## 3. 动载试验载荷与动载系数 φ_6（4.2.3.4.2，式 16）

- 加载方式：设备完成各种机构运动与组合运动，动载试验载荷作用于最不利位置。
- 载荷标准值（除合同或产品标准另有更高要求外）：**1.1 P**
- 结构验算时，动载试验载荷须再乘以**动载试验载荷起升动载系数 φ_6（式 16）**：
  - φ_6 = 0.5 · (1 + φ_2)
  - 其中 φ_2 为按式(7)与表 10/11 确定的起升动载系数。

## 4. 试验工况的载荷组合与安全系数（4.3.3.3、表 20、表 G.11、表 G.12）

- 试验工况归属 **载荷组合 C3**（特殊载荷情况）：
  - 常规自重乘 φ_1 + 试验载荷（动载试验乘 φ_6） + 组合 A1 对应非起升驱动机构加速力（乘 φ_5） + 试验风载（风速 ≤ 8.3 m/s） + 位移载荷。
- **许用应力法安全系数（表 22、表 G.11）**：载荷组合 C 取 **n = 1.22**（高危险度设备另乘 γ_n = 1.05~1.10）。
- **极限状态法系数（表 G.12）**：组合 C 中抗力系数 γ_m = 1.10，自重分项系数 1.05，试验载荷分项系数 1.10，驱动加速力 1.28，试验风载 1.05。
- **严禁混淆**：试验工况属于一次性或偶发特殊工况（组合 C），**不用于长期疲劳计算**，也**不作为正常使用静挠度限值的加载工况**（静挠度限值按 1.0 倍额定载荷校核）。

## 5. 仿真复核与现场实测对照要点

- 静载/动载试验有限元复核应重点输出：最不利主梁/弦杆/腹杆最大 von Mises 应力（≤ 组合 C 许用应力 σ_s / 1.22）、局部板件屈曲与悬臂根部支承反力、车轮最大静轮压（6.3.4.2.5 明确要求 P_max ≤ 1.9 k D l 须计入静/动载试验载荷！）。
- 实测挠度与仿真值比对时，必须明确加载基准、跨度/有效悬臂长度、是否扣除预拱度与支承沉降，以及卸载后的残余永久变形是否为零。

## 回答限制与最小输入清单

判断试验工况是否合格前必须确认：设备类型及是否适用专用标准（如 JT/T 1430—2022 的 1.5 倍静载 / 1.25 倍动载）、额定载荷、试验类型（静载/动载）、试验载荷位置、材料屈服强度、实测或仿真应力/挠度值及是否扣除预拱与残余变形。
