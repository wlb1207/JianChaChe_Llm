# 主梁与结构构件强度校核

Source: GB/T 3811-2008
Topic: 主梁与结构构件强度校核
SourceType: rule
Verified: true
Clause: 5.1, 5.2, 5.3.1, 5.4.1
Page: 标准正文第33-39页

## 适用范围

本知识块依据 GB/T 3811—2008 第 5.1、5.2、5.3.1、5.4.1 节，适用于起重机金属结构（主梁、端梁、桁架弦杆、腹杆、支腿、小车架及箱形梁等）在弹性工作阶段的静强度计算与有限元仿真应力评定。

- 第 5 章规定均限于钢材弹性范围内的计算（5.2.2.2.1）。
- 当外载荷使结构产生较大变形、内力与载荷呈非线性关系时，宜采用极限状态设计法或非线性有限元分析（5.2.1、5.6.3.2）。
- 强度计算应取载荷组合（4.3.3、表 20、附录 G）中最不利的作用位置、作用方向及机构运动组合（5.4.1.1）。

## 常用结构钢材与选用要求（5.3.1.1）

- 主要承载结构构件宜采用力学性能不低于 GB/T 700 中的 Q235 钢和 GB/T 699 中的 20 钢；采用高强度钢时，宜采用力学性能不低于 GB/T 1591 中的 Q345、Q390、Q420 钢（注：现行工程中 Q355B 对应并替代原 Q345B 强度等级，选材与设计值应结合现行钢材标准与 GB 50017 核对）。
- 厚度大于 50 mm 的钢板用作焊接承载构件时应慎重，用作拉伸、弯曲受力构件时须增加横向取样拉伸与冲击韧性检验。
- 铸钢件宜采用符合 GB/T 11352 或 GB/T 14408 的铸钢。
- 钢材屈服点 σs 应按板厚组别选取。

## 构件强度校核公式（5.4.1）

### 1. 轴向拉压与弯曲正应力

构件受拉、受压、受弯（含薄壁杆件约束弯曲正应力）的最大计算正应力应满足：

- 轴向拉压：σ = N / A_net ≤ [σ]（受压或摩擦型高强螺栓节点按 5.4.1.4 计入折减轴力 N' = N(1 - 0.5 Z1/Z)）
- 双向弯曲：σ = M_x / W_x + M_y / W_y ≤ [σ]

其中基本许用应力 [σ] 按表 22（σs/σb < 0.7）或式(28)（σs/σb ≥ 0.7）确定：
- 载荷组合 A（无风工作）：n = 1.48，[σ] = σs / 1.48
- 载荷组合 B（有风工作）：n = 1.34，[σ] = σs / 1.34
- 载荷组合 C（特殊或非工作）：n = 1.22，[σ] = σs / 1.22

### 2. 剪切应力（5.3.1.2.2）

构件剪切应力（含约束扭转剪应力）应满足式(29)：

- τ ≤ [τ] = [σ] / √3 ≈ 0.577 [σ]

### 3. 车轮或滑块下腹板局部压应力（5.4.1.2，式 31）

当车轮或滑块集中载荷作用于构件顶面、垫板或轨道上时，其下方腹板上边缘平均局部压应力按式(31)计算：

- σ_m = P / (t · c) ≤ [σ]
- 分布长度 c = l + 2 h_y

参数说明：
- P：单个车轮或滑块的集中载荷（N），**不计起升动载系数 φ2 及运行冲击系数 φ4**；
- t：腹板厚度（mm）；
- l：集中载荷作用长度（mm），滑块取滑块长度，**车轮取 l = 50 mm**；
- h_y：自轨道顶面（有轨道时）、垫板顶面（有垫板无轨道时）或构件顶面（无垫板无轨道时）至腹板上边缘的距离（mm）。

### 4. 复合应力（第四强度理论与 von Mises 等效应力，5.4.1.3）

在构件同一计算点同时存在多向应力时，应校核等效应力（各正应力带正负号，拉为正、压为负）：

- 正应力 σ、局部压应力 σ_m 与剪应力 τ 同点作用（式 32）：
  sqrt(σ² + σ_m² - σ·σ_m + 3τ²) ≤ [σ]
- 双向正应力 σ_x、σ_y 与剪应力 τ_xy 同点作用（式 33）：
  sqrt(σ_x² + σ_y² - σ_x·σ_y + 3τ_xy²) ≤ [σ]（且单项 |σ_x|≤[σ]、|σ_y|≤[σ]、|τ_xy|≤[τ]）
- 单向正应力 σ 与剪应力 τ 同点作用（式 34）：
  sqrt(σ² + 3τ²) ≤ [σ]

### 5. 端面承压（5.3.1.2.3，式 30）

- 端面承压许用应力：[σ_cd] = 1.4 [σ]

## 有限元仿真（ANSYS APDL）评定对应要点

- 线弹性静力仿真输出的 **von Mises 等效应力** 对应式(32)~(34)的第四强度理论判据，应与相应载荷组合（A/B/C）的母材基本许用应力 [σ] = σs / n 对比；若采用极限状态设计法，则将组合载荷乘以分项载荷系数 γpi 和高危险度系数 γn 后，与极限设计应力 lim σ = σs / γm（γm = 1.10）对比（5.2.2.2.4）。
- 桁架方管结构及悬臂根部节点处的局部网格尖角应力奇异，不能简单等同于名义弯曲应力，需区分名义膜应力、局部弯曲应力与焊缝热点应力。
- 强度校核合格不能替代刚度（5.5）、整体与局部稳定（5.6、5.7）和疲劳（5.8）校核。

## 回答限制与最小输入清单

判断是否满足强度要求前，应确认：
- 起重机或设备类型与结构形式（箱形梁、工字梁、空间桁架等）；
- 构件截面尺寸、壁厚与跨度/悬臂长度；
- 钢材牌号、厚度及对应屈服点 σs（高强钢还需 σb）；
- 载荷组合类型（A、B 或 C）与设计方法（许用应力法或极限状态法）；
- 最不利工况下的计算内力或有限元应力分量（σ_x、σ_y、τ_xy、σ_m、von Mises 应力）。

缺少材料屈服点、载荷组合或计算应力/内力时，只能说明校核公式与流程，不得直接给出合格结论。
