# 主梁强度校核

Source: GB/T 3811-2008
Topic: 主梁强度校核
SourceType: rule
Verified: true
Clause: 5.2, 5.3, 5.4, 4.3, 附录G
Page: 标准正文约33-42页，附录G约140-172页

## 适用范围

本知识块用于桥式起重机、门式起重机等桥架型起重机主梁及类似金属结构构件的强度校核。

GB/T 3811-2008 第5章规定了起重机金属结构构件及其连接的设计计算要求。主梁属于起重机主要承载金属结构，通常应按第4章确定计算载荷和载荷组合，再按第5章进行强度、刚性、稳定性和疲劳等验算。

## 主梁强度校核的基本原则

主梁强度校核应在最不利载荷组合、最不利载荷位置和最不利结构状态下进行。

应考虑的因素通常包括：

- 主梁自重；
- 小车自重；
- 额定起升载荷；
- 起升动载影响；
- 大车或小车运行引起的水平惯性力；
- 运行冲击载荷；
- 偏斜运行水平侧向载荷；
- 风载荷，适用于室外起重机；
- 试验载荷；
- 缓冲碰撞载荷；
- 意外停机或机构失效载荷；
- 局部轮压引起的腹板局部压应力；
- 焊缝、螺栓、销轴等连接处应力。

## 强度计算方法

GB/T 3811-2008 允许起重机金属结构设计采用：

1. 许用应力设计法；
2. 极限状态设计法。

标准正文第5章中的主要计算公式按许用应力设计法给出。若采用极限状态设计法，应按标准5.2.2.2.4和附录F进行换算。

## 常见主梁强度校核项目

主梁通常应校核以下项目：

### 1. 弯曲正应力

主梁受垂直载荷作用时，应计算危险截面的弯曲正应力。

常用形式：

\[
\sigma = \frac{M}{W}
\]

其中：

- \(\sigma\)：弯曲正应力；
- \(M\)：计算弯矩；
- \(W\)：截面抗弯模量。

校核条件：

\[
\sigma \leq [\sigma]
\]

### 2. 剪应力

主梁腹板应校核剪应力。

常用形式：

\[
\tau \leq [\tau]
\]

GB/T 3811-2008 规定剪切许用应力可按：

\[
[\tau] = \frac{[\sigma]}{\sqrt{3}}
\]

### 3. 局部压应力

当车轮或滑块上的集中载荷作用在构件顶面、垫板或轨道上时，应考虑腹板上边缘局部压应力。

标准5.4.1.2给出局部压应力计算原则：

\[
\sigma_m = \frac{P}{t c}
\]

校核条件：

\[
\sigma_m \leq [\sigma]
\]

其中：

- \(P\)：一个车轮或滑块上的集中载荷；
- \(t\)：腹板厚度；
- \(c\)：集中载荷分布长度。

### 4. 复合应力

当同一计算点同时存在正应力、剪应力和局部压应力时，应进行复合应力校核。

标准5.4.1.3给出形式：

\[
\sqrt{\sigma^2 + \sigma_m^2 - \sigma \sigma_m + 3\tau^2} \leq [\sigma]
\]

当存在两个方向正应力和剪应力时：

\[
\sqrt{\sigma_x^2 + \sigma_y^2 - \sigma_x\sigma_y + 3\tau_{xy}^2} \leq [\sigma]
\]

当只有拉压应力和剪应力时：

\[
\sqrt{\sigma^2 + 3\tau^2} \leq [\sigma]
\]

## 主梁连接强度校核

主梁常见连接包括：

- 对接焊缝；
- 角焊缝；
- 高强度螺栓连接；
- 普通螺栓连接；
- 铆钉连接；
- 销轴连接。

焊缝许用应力应按标准5.3.2.3.1和表23确定。  
普通螺栓、销轴连接许用应力应按标准5.3.2.3.2和表25确定。  
摩擦型高强度螺栓连接应按标准5.4.2.2.2.1计算。

## 重要设计注意事项

- 主梁强度校核必须先确定载荷组合。
- 对桥式和门式起重机，应优先参考附录G.4中的载荷组合。
- 许用应力设计法下，载荷组合A、B、C对应不同安全系数。
- 室外起重机应考虑工作状态风载荷和非工作状态风载荷。
- 对有疲劳要求的主梁，应单独进行疲劳强度校核。
- 对箱形梁腹板和翼缘板，应根据宽厚比、压应力、剪应力和局部压应力进行局部稳定校核。
- 对大跨度主梁，除强度外，还必须校核静态刚性和挠度。

## RAG回答限制

如果用户询问具体主梁截面是否合格，必须要求用户提供：

- 起重量；
- 跨度；
- 小车重量；
- 主梁截面尺寸；
- 材料牌号；
- 工作级别；
- 载荷组合；
- 轮压；
- 是否室外使用；
- 是否有疲劳要求。

若知识库没有给出具体参数，不得编造计算结果。
