# 许用应力

Source: GB/T 3811-2008
Topic: 许用应力
SourceType: rule
Verified: true
Clause: 5.2, 5.3, 5.4
Page: 标准正文约33-42页

## 适用范围

本知识块用于起重机金属结构按许用应力设计法进行强度校核时，确定材料、构件和连接的许用应力。

GB/T 3811-2008 第5章给出了起重机金属结构构件及连接按许用应力法进行设计计算的原则。

## 许用应力设计法

许用应力设计法的基本思想是：

结构构件在规定载荷组合下产生的计算应力，不应超过对应材料、连接形式和载荷组合下的许用应力。

基本校核形式：

\[
\sigma \leq [\sigma]
\]

其中：

- \(\sigma\)：计算正应力；
- \([\sigma]\)：许用正应力。

剪应力校核形式：

\[
\tau \leq [\tau]
\]

其中：

- \(\tau\)：计算剪应力；
- \([\tau]\)：许用剪应力。

## 基本许用应力

按许用应力设计法进行结构强度计算时，基本许用应力通常由材料屈服强度或强度设计指标除以安全系数得到。

常用表达形式：

\[
[\sigma] = \frac{f}{n}
\]

其中：

- \([\sigma]\)：基本许用应力；
- \(f\)：材料强度指标，通常与屈服强度相关；
- \(n\)：安全系数。

不同载荷组合对应不同安全系数，因此同一材料在不同载荷组合下可具有不同许用应力。

## 载荷组合对许用应力的影响

GB/T 3811-2008 将载荷组合划分为不同组合类别。  
许用应力法下，不同载荷组合对应不同安全系数。

一般原则：

- 正常工作工况采用较高安全储备；
- 特殊或偶然工况可采用不同安全系数；
- 试验、碰撞、非工作风等工况不得与正常长期疲劳工况混淆。

进行强度校核时，应先确定载荷组合，再确定该组合下的许用应力。

## 剪切许用应力

GB/T 3811-2008 中，剪切许用应力可按基本许用拉压应力换算。

常用关系：

\[
[\tau] = \frac{[\sigma]}{\sqrt{3}}
\]

其中：

- \([\tau]\)：许用剪应力；
- \([\sigma]\)：许用正应力。

## 复合应力许用条件

当构件同一点同时承受正应力和剪应力时，应按等效应力或复合应力进行校核。

常见形式：

\[
\sqrt{\sigma^2 + 3\tau^2} \leq [\sigma]
\]

当存在两个方向正应力和剪应力时：

\[
\sqrt{\sigma_x^2 + \sigma_y^2 - \sigma_x\sigma_y + 3\tau_{xy}^2} \leq [\sigma]
\]

当存在局部压应力时：

\[
\sqrt{\sigma^2 + \sigma_m^2 - \sigma\sigma_m + 3\tau^2} \leq [\sigma]
\]

其中：

- \(\sigma\)：正应力；
- \(\sigma_x, \sigma_y\)：两个方向的正应力；
- \(\sigma_m\)：局部压应力；
- \(\tau, \tau_{xy}\)：剪应力；
- \([\sigma]\)：许用正应力。

## 焊缝许用应力

焊缝许用应力应根据：

- 母材材料；
- 焊缝形式；
- 受力类型；
- 焊缝质量等级；
- 载荷组合；
- 标准表格规定；

综合确定。

常见焊缝校核包括：

- 对接焊缝拉压应力；
- 对接焊缝剪应力；
- 角焊缝有效截面剪应力；
- 组合焊缝复合应力；
- 受疲劳影响焊缝的疲劳强度。

焊缝许用应力不得简单等同于母材许用应力，应按标准中焊缝相关规定取值。

## 螺栓和销轴许用应力

普通螺栓、销轴和铆钉等连接件的许用应力应根据：

- 连接件材料；
- 受拉、受剪或承压状态；
- 孔壁承压；
- 载荷组合；
- 连接形式；
- 标准表格规定；

确定。

高强度螺栓连接还应区分：

- 摩擦型连接；
- 承压型连接；
- 预拉力；
- 摩擦面抗滑移系数；
- 抗滑移校核；
- 承载力校核。

## 局部压应力许用条件

车轮集中载荷通过轨道、垫板或翼缘作用于腹板时，应校核局部压应力。

常用形式：

\[
\sigma_m = \frac{P}{t c}
\]

校核条件：

\[
\sigma_m \leq [\sigma]
\]

其中：

- \(P\)：集中轮压；
- \(t\)：腹板厚度；
- \(c\)：集中载荷分布长度；
- \(\sigma_m\)：局部压应力；
- \([\sigma]\)：许用正应力。

## 使用许用应力时的注意事项

- 必须明确材料牌号和材料强度指标。
- 必须明确载荷组合。
- 必须明确计算对象是母材、焊缝、螺栓、销轴还是板件。
- 强度、稳定和疲劳对应的许用值不同，不可混用。
- 稳定校核中可能使用稳定系数或临界应力，不可简单套用强度许用应力。
- 疲劳校核应采用疲劳许用应力范围，不可直接使用静强度许用应力。
- 不同工况的许用应力和安全系数可能不同。

## RAG回答限制

如果用户询问“许用应力是多少”，必须要求用户提供：

- 材料牌号；
- 计算对象，是母材、焊缝、螺栓、销轴还是板件；
- 受力类型，是拉、压、弯、剪、承压还是复合应力；
- 载荷组合；
- 是否疲劳校核；
- 是否稳定校核；
- 焊缝或连接形式；
- 标准中对应表格或设计依据。

不得在缺少材料和载荷组合时直接给出许用应力数值。# 许用应力
