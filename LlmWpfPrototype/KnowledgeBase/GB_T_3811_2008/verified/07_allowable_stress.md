## 适用范围

本知识块依据 GB/T 3811—2008 第 5.3.1.2、5.3.2.3、5.4.2.2.2 节及表 22~表 27，给出许用应力设计法下结构钢材母材、焊缝、铆钉、普通螺栓、销轴及摩擦型高强度螺栓的许用应力与核心设计参数。

## 1. 结构构件钢材许用应力（5.3.1.2，表 22、式 28~30）

### 基本许用应力 [σ]（拉伸、压缩、弯曲）

- **屈强比 σ_s / σ_b < 0.7 的钢材（表 22）**：[σ] = σ_s / n
- **屈强比 σ_s / σ_b ≥ 0.7 的高强度钢材（式 28）**：[σ] = (0.5 σ_s + 0.35 σ_b) / n

| 载荷组合 | 强度安全系数 n（高危险度 γ_n = 1） | 基本许用应力 [σ]（σ_s/σ_b < 0.7） | 剪切许用应力 [τ] = [σ]/√3 | 端面承压 [σ_cd] = 1.4[σ] |
|---|---:|---|---|---|
| **载荷组合 A**（无风工作） | **1.48** | σ_s / 1.48 | 0.577 [σ] | 1.4 [σ] |
| **载荷组合 B**（有风工作） | **1.34** | σ_s / 1.34 | 0.577 [σ] | 1.4 [σ] |
| **载荷组合 C**（特殊或非工作） | **1.22** | σ_s / 1.22 | 0.577 [σ] | 1.4 [σ] |

### 常用结构钢材（壁厚 t ≤ 16 mm）基本许用应力参考换算

注：σ_s 必须按钢材实际厚度查现行 GB/T 700 / GB/T 1591 确定；高危险度场合安全系数应取 n = γ_fi · γ_n（γ_n = 1.05~1.10）。

- **Q235（t ≤ 16 mm，σ_s = 235 MPa，σ_s/σ_b < 0.7）**：
  - 组合 A：[σ] ≈ **158.8 MPa**，[τ] ≈ 91.7 MPa
  - 组合 B：[σ] ≈ **175.4 MPa**，[τ] ≈ 101.3 MPa
  - 组合 C：[σ] ≈ **192.6 MPa**，[τ] ≈ 111.2 MPa
- **Q345（t ≤ 16 mm，σ_s = 345 MPa，σ_b = 470~630 MPa；如按 σ_s/σ_b < 0.7）**：
  - 组合 A：[σ] ≈ **233.1 MPa**，[τ] ≈ 134.6 MPa
  - 组合 B：[σ] ≈ **257.5 MPa**，[τ] ≈ 148.6 MPa
  - 组合 C：[σ] ≈ **282.8 MPa**，[τ] ≈ 163.3 MPa
- **Q355B（现行 GB/T 1591—2018 替代 Q345B，t ≤ 16 mm，σ_s = 355 MPa，σ_b ≥ 470 MPa，注意屈强比 σ_s/σ_b = 355/470 ≈ 0.755 ≥ 0.7）**：
  - 若严格按屈服点比表 22：组合 A ≈ 239.9 MPa，组合 B ≈ 264.9 MPa，组合 C ≈ 291.0 MPa；
  - 若按高强钢式(28)（取 σ_s = 355，σ_b = 470，分子 0.5×355 + 0.35×470 = 342.0 MPa）：组合 A ≈ **231.1 MPa**，组合 B ≈ **255.2 MPa**，组合 C ≈ **280.3 MPa**（更为安全保守，设计评定时应明确采用哪一依据）。

## 2. 焊缝许用应力（5.3.2.3.1，表 23）

焊缝应具有与母材同等的综合机械性能，质量分级按 GB/T 19418：

| 焊缝型式与质量分级 | 纵向拉、压许用应力 [σ_h] | 剪切许用应力 [τ_h] |
|---|---|---|
| 对接焊缝（B 级、C 级） | [σ] | [σ] / √2 ≈ 0.707 [σ] |
| 对接焊缝（D 级） | 0.8 [σ] | 0.8 [σ] / √2 ≈ 0.566 [σ] |
| 角焊缝（自动焊、手工焊） | — | [σ] / √2 ≈ 0.707 [σ] |

注：施工条件较差或受横向载荷的焊缝，许用应力宜适当降低；疲劳许用应力见 5.8.5 表 32。

## 回答限制与最小输入清单

给出具体许用应力数值前，必须明确：材料牌号及板厚、是否属于高强钢（σ_s/σ_b ≥ 0.7）、载荷组合（A/B/C）、是否高危险度场合（γ_n）、计算对象（母材/焊缝/螺栓/销轴）以及是否属于静强度而非疲劳或稳定校核。
