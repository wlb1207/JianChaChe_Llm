## 适用范围与设计方法（5.8）

本知识块依据 GB/T 3811—2008 第 5.8 节及规范性**附录 O**（注意：附录 O 为疲劳应力集中等级与接头型式；附录 P 为电动机初选，与疲劳无关），适用于承受反复循环载荷的起重机金属结构构件与连接件的疲劳强度校核。

- GB/T 3811—2008 明确说明结构疲劳计算有应力比法和应力幅法两种，**本标准采用应力比法**（5.8）。
- 疲劳计算一律采用许用应力设计法（5.2.2.2.3），最大应力按**载荷组合 A（A1~A4，无风常规工作载荷）**中最不利工况确定（5.8.1、4.3.4.2.6）。
- **需校核边界（5.8.4）**：通常结构件工作级别为 **E4 级（含）以上** 应校核疲劳强度；E1~E3 级且为轻微/中等应力集中等级、或计算出的疲劳许用应力 [σ_r] 已大于静强度基本许用应力 [σ] 时，可不必进行单项疲劳核算（5.8.6）。

## 1. 应力循环特性 r（5.8.2，式 72）

在同一疲劳计算点上，取绝对值最大应力 σ_xmax、σ_ymax、τ_xymax 与对应循环中产生最大差值绝对值的最小应力 σ_xmin、σ_ymin、τ_xymin（拉为正、压为负）：

- r_x = σ_xmin / σ_xmax
- r_y = σ_ymin / σ_ymax
- r_xy = τ_xymin / τ_xymax

注：移动小车轮压引起的脉动局部压应力，取 r = 0。

## 2. 构件连接应力集中情况等级（5.8.3、附录 O）

按应力集中程度递增（疲劳强度递减）划分：
- **非焊接件**：W0（实体无接缝母材）、W1（钻孔或满载摩擦型高强螺栓连接）、W2（普通螺栓/铆钉受剪钻孔构件）；
- **焊接件**：K0（轻度）→ K1（适度）→ K2（中等）→ K3（严重）→ K4（非常严重）。
- 规范建议：**尽量采用合理的应力集中等级，推荐采用 K2，尽量避免采用 K4**（5.8.3）。

### 附录 O 典型接头等级速查（表 O.1、表 O.2）

表 O.1 将焊接质量分为 **特殊质量（S.Q，焊根清根、焊缝磨平、100% 探伤 P100）** 与 **普通质量（O.Q，应力 > 0.8[σ] 时 P100，否则 P10）**：

| 等级 | 典型构件与焊缝接头型式（表 O.2） |
|---|---|
| W0 / W1 / W2 | W0 无接缝实体母材；W1 摩擦型高强螺栓（100% 承载）或 ≤20% 承载普通螺栓孔；W2 承受双剪/单剪的普通螺栓/铆钉孔 |
| K0（轻度） | 垂直于受力方向的 S.Q 对接焊缝（含 1:4~1:5 不对称/1:3 对称过渡）；平行于受力方向的 O.Q 对接焊/角焊/翼腹板焊缝；纵向剪切对接或角焊缝 |
| K1（适度） | 垂直于受力方向的 O.Q 对接焊缝（1:4~1:5 过渡）；垂直受力方向的 S.Q 连续 K 形焊；包角 S.Q 腹板加劲肋角焊 |
| K2（中等，推荐） | 垂直受力的 1:3 不对称过渡 O.Q 对接焊；型钢/节点板 S.Q 对接焊；S.Q 横隔板/加劲肋角焊（含切角不包角）；端部圆弧/斜度打磨的纵向对接/K形焊；S.Q 十字形 K 形焊 |
| K3（严重） | 1:2 过渡或无斜度对称 O.Q 对接焊；带垫板无封底焊的管件对接（3.12）；O.Q 横向角焊连接腹板/加劲肋；O.Q 十字 K 形焊；**S.Q 角焊缝将型钢或管子焊到连续主构件上（3.6）** |
| K4（非常严重，避免） | 无斜度不对称 O.Q 对接焊；无辅助角撑扁钢十字对接；直角端部构件纵向角焊；槽焊/塞焊；O.Q 角焊十字接头；**O.Q 角焊缝将型钢或管子直接焊到连续主构件上（4.6）** |

> 工程提醒：空心方管桁架支管直接用普通质量角焊缝（O.Q）焊在连续弦杆上对应 **K4（4.6）**，改用特殊质量打磨角焊缝（S.Q）可提升至 **K3（3.6）**，节点疲劳寿命差距极大！

## 3. 疲劳许用应力公式（5.8.5，表 31、表 32）

### 表 31 构件疲劳许用应力

| 应力循环特性 r | 受力性质 | 疲劳许用应力计算公式 | 上限截断值 |
|---|---|---|---|
| -1 ≤ r ≤ 0 | 拉伸 t | [σ_rt] = [5 / (3 - 2r)] · [σ_-1] | ≤ 0.75 σ_b |
| -1 ≤ r ≤ 0 | 压缩 c | [σ_rc] = [2 / (1 - r)] · [σ_-1] | ≤ 0.90 σ_b |
| 0 < r ≤ 1 | 拉伸 t | [σ_rt] = 1.67 [σ_-1] / [1 - (1 - [σ_-1]/(0.45 σ_b)) · r] | ≤ 0.75 σ_b |
| 0 < r ≤ 1 | 压缩 c | [σ_rc] = 1.2 [σ_rt] = 2 [σ_-1] / [1 - (1 - [σ_-1]/(0.45 σ_b)) · r] | ≤ 0.90 σ_b |
| -1 ≤ r ≤ 1 | 剪切 | [τ_xyr] = [σ_rt(按W0及剪应力r算)] / √3 | ≤ 0.75 σ_b / √3 |

注：Q235 取 σ_b = 370 N/mm²；Q345 取 σ_b = 490 N/mm²。

### 表 32 连接件疲劳许用应力

- **焊缝拉/压**：同表 31 构件公式；
- **焊缝剪切**：[τ_xyr] = [σ_rt(按K0及剪应力r算)] / √2，上限 0.75 σ_b / √2；
- **A、B 级螺栓或铆钉**：拉压一般不作疲劳计算（尽量避免受拉）；单剪 [τ_xyr] = 0.6 [σ_rt(W2)]（≤ 0.45 σ_b）；双剪 [τ_xyr] = 0.8 [σ_rt(W2)]（≤ 0.60 σ_b）；承压 [τ_cyr] = 2.5 [τ_xyr]。

## 4. 疲劳强度校核公式（5.8.6，式 73~76）

- 单向正应力：|σ_xmax| ≤ [σ_xrt] 或 [σ_xrc]；|σ_ymax| ≤ [σ_yrt] 或 [σ_yrc]
- 剪应力：|τ_xymax| ≤ [τ_xyr]
- 平面复合疲劳应力（式 76，分子中 σ_xmax、σ_ymax 带正负号）：
  (σ_xmax / [σ_xr])² + (σ_ymax / [σ_yr])² - (σ_xmax · σ_ymax) / ([σ_xr] · [σ_yr]) + (τ_xymax / [τ_xyr])² ≤ 1.1

## 回答限制与最小输入清单

进行疲劳强度判断前必须确认：结构件工作级别（E1~E8）、组合 A 下的最大与最小应力（σ_max、σ_min 及应力比 r）、接头型式与应力集中等级（W0~W2 或 K0~K4）、焊接质量与探伤要求（S.Q / O.Q）及材料抗拉强度 σ_b。
