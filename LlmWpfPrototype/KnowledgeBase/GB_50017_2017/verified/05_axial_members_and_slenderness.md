# 轴心受力构件强度、稳定性、计算长度与容许长细比

Source: GB 50017-2017
Topic: 轴心受力构件稳定、钢管桁架计算长度与容许长细比
SourceType: rule
Verified: true
Clause: 7.1, 7.2, 7.3, 7.4, 表7.2.1-1, 表7.4.1-2, 表7.4.6, 表7.4.7

## 适用范围

本知识块依据 GB 50017—2017 第 7 章，规定桁架弦杆和腹杆等轴心拉、压构件的截面强度、整体稳定性、钢管桁架计算长度及容许长细比控制边界。

## 轴心受力截面强度（7.1.1, 7.1.2）

- 轴心受拉/受压毛截面屈服：
\[
\sigma = \frac{N}{A} \le f
\]
- 轴心受拉净截面断裂（或含虚孔受压构件孔心截面）：
\[
\sigma = \frac{N}{A_n} \le 0.7 f_u
\]

## 轴心受压构件整体稳定（7.2.1）

\[
\frac{N}{\varphi A f} \le 1.0
\]

其中稳定系数 \(\varphi\) 按长细比 \(\lambda = l_0 / i\)、钢材屈服强度及截面分类确定：
- **板厚 `t < 40 mm` 的箱形/方管截面（表7.2.1-1）**：
  - 轧制无缝/焊接且板件宽厚比 `> 20`：对 x、y 轴均为 **`b` 类**；
  - 轧制/焊接且板件宽厚比 `≤ 20`（如厚壁小方管 70×70×5 净宽厚比 12）：对 x、y 轴均为 **`c` 类**。

## 钢管桁架构件计算长度 \(l_0\)（表7.4.1-2）

采用相贯焊接连接的钢管桁架：
- **平面桁架**：弦杆平面内 `0.9 l`、平面外 `l1`（平面外无支撑长度）；支座斜杆/竖杆平面内 `0.8 l`、平面外 `l`；其他腹杆平面内 `0.8 l`、平面外 `l`。
- **立体桁架（空间格构桁架）**：弦杆 `0.9 l`（同时应以 `0.9 l1` 按格构式压杆验算整体稳定）；支座斜杆/竖杆 `0.8 l`；其他腹杆 `0.8 l`。

## 受压构件容许长细比（7.4.6 表7.4.6）

- 轴心受压柱、**桁架和天窗架中的压杆**：容许长细比 **`150`**；
- 跨度 `≥ 60 m` 的桁架受压弦杆、端压杆及**直接承受动力荷载的受压腹杆**：不宜大于 **`120`**；
- 柱的缀条、吊车桁架以下柱间支撑：`150`；
- 一般支撑及减小受压构件计算长度的杆件：`200`；当杆件内力设计值不大于承载能力的 `50%` 时，受压容许长细比可放宽至 `200`。

## 受拉构件容许长细比（7.4.7 表7.4.7）

- **桁架受拉构件**：
  - 一般静载建筑结构：`350`；
  - **对腹杆提供平面外支点的弦杆**：`250`；
  - **直接承受动力荷载的结构** / 有重级工作制起重机厂房：`250`；
- 中级、重级工作制吊车桁架下弦杆：不宜超过 **`200`**；
- 受拉构件在永久荷载与风荷载组合下出现受压时：不宜超过 **`250`**。

## 工程设计边界提示

- 桁架弦杆缩减截面外宽或外高会同步减小回转半径 \(i\)、增大长细比 \(\lambda = l_0 / i\)，进而显著降低轴压稳定系数 \(\varphi\)；设计改型时必须复核受压弦杆与腹杆的长细比（`≤ 150`，动载腹杆 `≤ 120`）及压杆稳定承载力。
