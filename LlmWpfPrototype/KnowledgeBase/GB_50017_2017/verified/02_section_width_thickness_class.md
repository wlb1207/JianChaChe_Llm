# 截面板件宽厚比等级与箱形/方管局部稳定宽厚比限值

Source: GB 50017-2017
Topic: 截面板件宽厚比等级与箱形截面局部稳定限值
SourceType: rule
Verified: true
Clause: 3.5, 表3.5.1, 表3.5.2, 7.3.1, 7.3.4
Page: 标准正文第15-17页、第68-70页

## 适用范围

本知识块依据 GB 50017—2017 第 3.5 节与第 7.3 节，规定受弯、压弯及轴心受压构件（特别是闭口箱形/方矩形管截面）的板件宽厚比等级划分与局部不失稳边界条件。

## 钢号修正系数

\[
\varepsilon_k = \sqrt{\frac{235}{f_y}}
\]

其中 \(f_y\) 为钢材牌号对应的屈服点数值（例如 Q235 取 `1.00`，Q345 约 `0.825`，Q355 约 `0.814`）。

## 箱形/方矩形管截面壁板宽厚比等级（表3.5.1）

对箱形截面，\(b_0\) 为两壁板间的净距离，\(t\) 为壁板厚度：

- **压弯构件（箱形截面壁板间翼缘 \(b_0 / t\)）**：
  - `S1` 级：\(\le 30\varepsilon_k\)
  - `S2` 级：\(\le 35\varepsilon_k\)
  - `S3` 级：\(\le 40\varepsilon_k\)
  - `S4` 级：\(\le 45\varepsilon_k\)
- **受弯构件（箱形截面壁板间翼缘 \(b_0 / t\)）**：
  - `S1` 级：\(\le 25\varepsilon_k\)
  - `S2` 级：\(\le 32\varepsilon_k\)
  - `S3` 级：\(\le 37\varepsilon_k\)
  - `S4` 级：\(\le 42\varepsilon_k\)
- **箱形截面腹板**：单向受弯箱形截面腹板宽厚比限值可按 H 形截面腹板采用（受弯 S1~S4：`65εk / 72εk / 93εk / 124εk`；压弯按应力梯度系数 \(\alpha_0 = (\sigma_{\max} - \sigma_{\min})\) 对应公式计算）。
- **圆钢管径厚比 \(D/t\)（压弯构件）**：S1~S4 分别为 \(50\varepsilon_k^2\)、\(70\varepsilon_k^2\)、\(90\varepsilon_k^2\)、\(100\varepsilon_k^2\)。

## 轴心受压箱形截面局部稳定边界（7.3.1, 7.3.4）

- 要求不出现局部失稳的实腹轴心受压箱形截面壁板宽厚比限值（7.3.1-3）：
\[
\frac{b}{t} \le 40\varepsilon_k
\]
- 有效截面折减阈值（7.3.4-1）：当箱形截面壁板 \(b/t \le 42\varepsilon_k\) 时，有效截面系数 \(\rho = 1.0\)（全截面有效）；当 \(b/t > 42\varepsilon_k\) 时须按有效宽度折减或设置纵向加劲肋。
- 压力低于稳定承载力 \(\varphi A f\) 时，宽厚比限值可乘放大系数 \(\alpha = \sqrt{\varphi A f / N}\)（7.3.2）。

## 工程设计边界提示

- 桁架受压弦杆（如大悬臂桥梁检查车斜桁架下弦杆）在进行轻量化“增大外廓、减薄壁厚”探索时，必须核对闭口方管净宽厚比 \(b_0/t\) 是否超过 `40εk`（轴压）或 `45εk`（压弯 S4 级），避免壁厚过薄引发局部鼓曲失稳。
