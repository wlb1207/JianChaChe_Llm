# 矩形与方形钢管直接焊接节点构造及承载力边界

Source: GB 50017-2017
Topic: 矩形钢管与方管桁架直接焊接节点构造及计算
SourceType: rule
Verified: true
Clause: 13.1, 13.2, 13.4, 表13.4.1
Page: 标准正文第145-149页、第167-176页

## 适用范围

本知识块依据 GB 50017—2017 第 13.1、13.2 与 13.4 节，专门规定方形/矩形钢管桁架直接焊接相贯节点与局部加劲节点的几何适用范围、构造边界和承载力校核原则（直接对应方管格构桁架主管-支管节点）。

## 钢管桁架节点一般与构造边界（13.1, 13.2）

- **管件宽厚比总限值（13.1.2）**：
  - 圆钢管外径与壁厚比 `D / t ≤ 100 εk²`；
  - **方（矩）形管最大外缘尺寸与壁厚之比不应超过 `40 εk`**（例如 Q345/Q355 约为 `32.5~33`）。
- **主支管匹配硬性构造要求（13.2.1）**：
  - **主管外部尺寸不应小于支管外部尺寸，主管壁厚不应小于支管壁厚**；不得将支管插入主管内；
  - 主管与支管或支管轴线间夹角**不宜小于 `30°`**；
  - 节点偏心宜避免；不可避免时应满足：`-0.55 ≤ e / h ≤ 0.25`（受压主管须计入偏心弯矩 `M = ΔN · e`，13.1.4）；
  - 支管壁厚 `< 6 mm` 时可不切坡口；主支管夹角 `≥ 120°` 区域宜采用对接焊缝或带坡口角焊缝；角焊缝焊脚尺寸不宜大于支管壁厚的 `2` 倍；
  - 相邻支管间间隙 `a` 不应小于两支管壁厚之和 `t1 + t2`；搭接型 K/N 节点搭接率应满足 `25% ≤ ηov ≤ 100%`（小尺寸/薄壁支管搭接在大尺寸/厚壁支管上，受压支管宜在下方，13.2.2）。

## 矩形主管节点几何参数适用范围（表13.4.1）

- 支管与主管宽度比：T/Y/X 与 K/N 搭接节点 `bi / b ≥ 0.25`；K/N 间隙节点 `bi / b ≥ 0.1 + 0.01 (b/t)` 且 `β ≥ 0.35`；
- 主管宽厚比 `b/t`、`h/t`：T/Y/X 与 K/N 间隙节点 `≤ 35`，K/N 搭接节点 `≤ 40`；
- 支管受压宽厚比 `bi/ti`、`hi/ti`：T/Y/X 与 K/N 间隙节点 `≤ 37 εk,i` 且 `≤ 35`；K/N 搭接节点 `≤ 33 εk,i`；受拉支管 `≤ 35`；
- 矩形支管高宽比：`0.5 ≤ hi / bi ≤ 2.0`。

## 节点加强与焊缝校核（13.2.3, 13.2.4, 13.4.4, 13.4.5）

- 无加劲直接焊接节点承载力不足时，可在方管主管内设置 2 块横向加劲板（厚度不小于支管壁厚且不宜小于主管壁厚的 `2/3`），或在主管表面贴焊四周围焊加强板（连接表面加强板厚度不宜小于支管最大厚度的 `2` 倍，焊前钻排气孔焊后塞焊封闭）。
- 节点焊缝承载力不应小于节点承载力，全周角焊缝承载力按 `Nf = he * lw * ff^w` 计算，并按 13.4.5-2~4 根据节点类型与支管倾角确定焊缝有效计算长度 `lw`。

## 工程改型边界提醒

- 单独缩小上弦杆或下弦杆方管尺寸/壁厚时，务必核对是否仍满足“主管尺寸与壁厚不小于相连腹杆/横管支管”以及 `b/t ≤ 35`（或 `40 εk`），否则节点局部冲剪或管壁压屈将成为结构薄弱环节。
