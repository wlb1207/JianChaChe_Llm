# 螺栓连接、销轴连接与钢管法兰连接构造

Source: GB 50017-2017
Topic: 高强度螺栓、销轴连接与钢管法兰连接构造
SourceType: rule
Verified: true
Clause: 11.4, 11.5, 11.6, 11.7, 表11.4.2-1, 表11.4.2-2, 表11.5.1, 表11.5.2
Page: 标准正文第117-127页

## 适用范围

本知识块依据 GB 50017—2017 第 11.4~11.7 节，规定普通螺栓、高强度螺栓（摩擦型/承压型）、销轴连接以及钢管法兰连接的承载力与构造边界条件。

## 高强度螺栓连接计算与动载限制（11.4.2, 11.4.3, 11.5.3, 11.5.4）

- **摩擦型高强度螺栓受剪承载力设计值（11.4.2-1）**：
\[
N_v^b = 0.9 k n_f \mu P
\]
  - 孔型系数 \(k\)：标准孔 `1.0`，大圆孔 `0.85`，槽孔垂直内力 `0.7`、平行内力 `0.6`；
  - 抗滑移系数 \(\mu\)（表 11.4.2-1，Q345）：喷硬质石英砂/铸钢棱角砂 `0.45`，抛丸/喷砂 `0.40`，钢丝刷除浮锈 `0.35`；
  - 预拉力设计值 \(P\)（表 11.4.2-2）：`8.8` 级 M16/M20/M22/M24/M27/M30 分别为 `80 / 125 / 150 / 175 / 230 / 280 kN`；`10.9` 级分别为 `100 / 155 / 190 / 225 / 290 / 355 kN`。
- 摩擦型螺栓轴向受拉承载力：\(N_t^b = 0.8 P\)（11.4.2-2）。
- **直接承受动力荷载构件的强制规定（11.5.3, 11.5.4-3）**：
  - 抗剪连接**应采用摩擦型高强度螺栓**，**承压型高强度螺栓不应用于直接承受动力荷载的结构**；
  - 普通螺栓受拉连接应采取双螺帽等有效防松措施。

## 螺栓孔距、边距与端距边界（表11.5.2）

- 最小中心间距：`3 d0`；最大中心间距：外排 `min(8 d0, 12 t)`，中间排受压 `min(12 d0, 18 t)`、受拉 `min(16 d0, 24 t)`；
- 最小边距/端距：顺内力方向端距 `2 d0`；垂直内力方向剪切/手工割边 `1.5 d0`，轧制/自动气割边高强螺栓 `1.5 d0`、其他螺栓 `1.2 d0`；最大边距 `min(4 d0, 8 t)`。
- 每一杆件一端永久性螺栓数不宜少于 `2` 个；沿杆轴受拉的端板（法兰板）宜设置加劲肋（11.5.6）。

## 销轴连接构造与强度（11.6）

- 销轴与耳板宜用 Q345/Q390/Q420 或 45 号钢、35CrMo、40Cr；销轴直径 `> 120 mm` 宜锻造（11.6.1）。
- 孔径与销轴直径差不应大于 `1 mm`；耳板两侧宽厚比 `b/t` 不宜大于 `4`，且端部净距 `a ≥ 4/3 b_e`（\(b_e = 2t + 16 \le b\)）（11.6.2）。
- 销轴须验算承压、抗剪、抗弯及弯剪组合强度，耳板须验算净截面抗拉、端部劈裂抗拉与端部抗剪强度（11.6.3, 11.6.4）。

## 钢管法兰连接构造边界（11.7）

- 法兰板可采用环状板或整板，并宜设置加劲肋（11.7.1）。
- 法兰板上螺孔应均匀分布，螺栓宜采用较高强度等级（11.7.2）。
- **防内壁腐蚀封闭要求（11.7.3）**：当钢管内壁不作防腐处理时，管端部法兰**应作气密性焊接封闭**；若采用热浸镀锌作内外防腐，则管端不应封闭。
