# 钢结构或构件变形容许值与预起拱规定

Source: GB 50017-2017
Topic: 钢结构受弯构件与大跨度桁架变形容许值
SourceType: rule
Verified: true
Clause: 3.4, 附录B, 表B.1.1, 表B.2.4-1
Page: 标准正文第15页、第238-242页

## 适用范围

本知识块依据 GB 50017—2017 第 3.4 节与附录 B，规定钢结构受弯构件、吊车桁架、工作平台梁及大跨度桁架/悬挑结构的正常使用变形容许值与预起拱原则。

## 变形计算一般原则（3.4）

- 计算结构或构件变形时，**可不考虑螺栓或铆钉孔引起的截面削弱**（3.4.2）。
- 横向受力构件可预先起拱，起拱值可取恒载标准值加 `1/2` 活载标准值产生的挠度；仅改善外观时，挠度取恒载+活载标准值挠度减去起拱值（3.4.3）。
- 竖向和水平荷载引起的振动应满足正常使用或舒适度要求（3.4.4）。

## 受弯构件挠度容许值摘要（表B.1.1）

表中 \(l\) 为跨度；**对悬臂梁和伸臂梁，\(l\) 取悬臂长度的 2 倍**（表 B.1.1 注 1）：
- **吊车梁和吊车桁架**（仅按可变荷载 \([v_Q]\)）：
  - 手动起重机和单梁起重机（含悬挂起重机）：`l / 500`
  - 轻级工作制桥式起重机：`l / 750`
  - 中级工作制桥式起重机：`l / 900`
  - 重级工作制桥式起重机：`l / 1000`
  - 当吊车梁或吊车桁架跨度 `> 12 m` 时，其容许值应乘以 `0.9`（注 3）。
- **手动或电动葫芦轨道梁**：`l / 400`。
- **工作平台梁/楼（屋）盖主梁或桁架（含设有悬挂起重设备的梁和桁架）**：总挠度 \([v_T] = l / 400\)，可变荷载挠度 \([v_Q] = l / 500\)。

## 大跨度钢结构容许挠度值（表B.2.4-1）

- 受弯为主的桁架、网架等：屋盖跨中 `L/250`、悬挑 `L/125`；楼盖跨中 `L/300`、悬挑 `L/150`；
- 设有悬挂起重设备的屋盖结构：最大挠度不宜大于跨度的 `1/400`，可变荷载下不宜大于 `1/500`。

## 与专项标准的边界衔接

- GB 50017 附录 B 为通用建筑与工业钢结构变形容许值；对于公路桥梁悬挂式检查车桁架，应优先满足专项行标 JT/T 1430—2022 表 3（钢桁架简支 `L/800`、悬臂端 `L'/400`）的更严格控制边界。
