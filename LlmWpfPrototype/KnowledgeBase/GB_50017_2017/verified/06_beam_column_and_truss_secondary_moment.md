# 拉弯压弯构件稳定性与承受次弯矩的箱形桁架杆件

Source: GB 50017-2017
Topic: 拉弯压弯构件计算与承受次弯矩的方箱形桁架杆件
SourceType: rule
Verified: true
Clause: 5.1.5, 8.1, 8.2, 8.4, 8.5, 表8.1.1, 表8.5.2

## 适用范围

本知识块依据 GB 50017—2017 第 5.1.5 条与第 8 章，规定同时承受轴力与弯矩的箱形/方管构件（如大悬臂桁架弦杆、受局部轮压/集中力作用的弦杆及刚接方管桁架杆件）的强度、稳定与次弯矩验算边界。

## 拉弯与压弯构件截面强度（8.1.1）

\[
\frac{N}{A_n} \pm \frac{M_x}{\gamma_x W_{nx}} \pm \frac{M_y}{\gamma_y W_{ny}} \le f
\]

- 截面板件宽厚比不满足 `S3` 级要求或需要验算疲劳时，塑性发展系数 \(\gamma_x = \gamma_y = 1.0\)；
- 满足 `S3` 级且不需疲劳验算时，箱形截面可取 \(\gamma_x = \gamma_y = 1.05\)（表 8.1.1）。

## 实腹式箱形压弯构件稳定性（8.2.1, 8.2.5）

- 单向压弯平面内稳定：
\[
\frac{N}{\varphi_x A f} + \frac{\beta_{mx} M_x}{\gamma_x W_{1x}(1 - 0.8 N / N'_{Ex}) f} \le 1.0
\]
- 平面外稳定：
\[
\frac{N}{\varphi_y A f} + \eta \frac{\beta_{tx} M_x}{\varphi_b W_{1x} f} \le 1.0
\]
- **闭口箱形截面关键参数优势（8.2.1, 8.2.5）**：
  - 均匀弯曲整体稳定系数 \(\varphi_b = 1.0\)（双向压弯 \(\varphi_{bx} = \varphi_{by} = 1.0\)）；
  - 截面影响系数 \(\eta = 0.7\)（开口截面为 `1.0`）。
- 压弯构件局部稳定（8.4.1）：要求不出现局部失稳时，板件宽厚比应满足表 3.5.1 压弯构件 `S4` 级要求（箱形壁板 \(b_0 / t \le 45\varepsilon_k\)）；超限时按 8.4.2 有效截面折减计算。

## 桁架节点铰接假定与次弯矩边界（5.1.5, 8.5）

- **直接相贯焊接钢管桁架视为铰接节点的几何前提（5.1.5-3）**：须同时满足第 13 章节点几何适用范围，且**主管节间长度与截面高度之比 `≥ 12`**、**支管杆间长度与截面高度之比 `≥ 24`**。
- **不满足铰接假定时（5.1.5-4, 8.5.1, 8.5.2）**：方箱形截面桁架应按刚接桁架计入节点刚性引起的次弯矩 \(M\)；对满足压弯 `S2` 级宽厚比的杆件，当 \(\varepsilon = M / (N W / A) > 0.2\) 时可按塑性重分布公式验算端部强度：
\[
\frac{N}{A} + \alpha \frac{M}{W_p} \le \beta f
\]
其中**正方箱形截面**（表 8.5.2）：\(\alpha = 0.80\)，\(\beta = 1.13\)；整体稳定仍须按 8.2 节压弯构件验算。
