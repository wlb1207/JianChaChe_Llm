# 受弯构件强度、箱形截面整体稳定与局部稳定

Source: GB 50017-2017
Topic: 受弯构件强度、整体稳定与腹板局部稳定
SourceType: rule
Verified: true
Clause: 6.1, 6.2, 6.3
Page: 标准正文第37-48页

## 适用范围

本知识块依据 GB 50017—2017 第 6 章，规定实腹式受弯构件（含箱形截面与工字形截面）的抗弯、抗剪、局部承压、折算应力强度校核及整体/局部稳定边界。

## 受弯强度与塑性发展系数（6.1.1, 6.1.2）

双向受弯强度验算公式：
\[
\frac{M_x}{\gamma_x W_{nx}} + \frac{M_y}{\gamma_y W_{ny}} \le f
\]

截面塑性发展系数取值规定（6.1.2）：
- 截面板件宽厚比等级为 `S4` 或 `S5` 级时：**取 \(\gamma_x = \gamma_y = 1.0\)**；
- 截面板件宽厚比等级为 `S1`、`S2`、`S3` 级时：
  - 工字形截面：\(\gamma_x = 1.05\)，\(\gamma_y = 1.20\)；
  - **箱形截面**：\(\gamma_x = \gamma_y = 1.05\)；
- **需要计算疲劳的梁**：宜取 \(\gamma_x = \gamma_y = 1.0\)。

## 受剪强度与腹板折算应力（6.1.3, 6.1.5）

- 受剪强度：\(\tau = \frac{VS}{I t_w} \le f_v\)
- 同时承受较大正应力 \(\sigma\)、剪应力 \(\tau\) 和局部压应力 \(\sigma_c\) 时折算应力验算：
\[
\sqrt{\sigma^2 + \sigma_c^2 - \sigma\sigma_c + 3\tau^2} \le \beta_1 f
\]
其中 \(\sigma\) 与 \(\sigma_c\) 异号时 \(\beta_1 = 1.2\)，同号或 \(\sigma_c = 0\) 时 \(\beta_1 = 1.1\)。

## 整体稳定性与箱形截面免算边界（6.2）

- 铺板密铺在受压翼缘并牢固相连阻止侧移时，可不计算整体稳定（6.2.1）。
- **箱形截面简支梁免算整体稳定条件（6.2.4）**：当截面高度与壁板间距之比 \(h / b_0 \le 6\)，且受压翼缘侧向支承点间距满足：
\[
\frac{l_1}{b_0} \le 95\varepsilon_k^2
\]
可不计算整体稳定性（这体现了闭口箱形/方管截面优异的抗扭与侧向稳定性能）。
- 梁支座处应采取防端截面扭转构造措施（6.2.5）。

## 局部稳定与加劲肋边界（6.3）

- 不考虑腹板屈曲后强度时，当焊接梁腹板 \(h_0 / t_w > 80\varepsilon_k\) 应计算腹板局部稳定并宜配横向加劲肋；\(h_0 / t_w\) 不宜超过 `250`（6.3.1, 6.3.2）。
- 直接承受动力荷载的吊车梁类构件，\(h_0 / t_w > 80\varepsilon_k\) 应配横向加劲肋，支座及较大固定集中荷载处宜设支承加劲肋。
