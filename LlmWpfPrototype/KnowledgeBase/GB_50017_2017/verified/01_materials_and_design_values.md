## 适用范围

本知识块依据《钢结构设计标准》（GB 50017—2017）第 4 章，规定承重钢结构常用牌号、质量等级选用边界、钢材与无缝钢管强度设计值、焊缝与螺栓强度设计值及物理性能指标。

## 钢材牌号与质量等级边界（4.1, 4.3）

- 常用牌号包括 `Q235`、`Q345`、`Q390`、`Q420`、`Q460` 和 `Q345GJ`（符合 GB/T 700、GB/T 1591 等）；耐候钢可选 `Q235NH`、`Q355NH`、`Q415NH`（GB/T 4171）。注：现行 GB/T 1591—2018 中 `Q355` 替代原 `Q345` 牌号，具体强度设计值取值须注明标准衔接。
- **直接承受动力荷载或需验算疲劳的焊接结构质量等级（4.3.3）**：
  - 工作温度 `> 0 ℃`：不应低于 `B` 级；
  - 工作温度 `-20 ℃ < T ≤ 0 ℃`：Q235、Q345 不应低于 `C` 级，Q390~Q460 不应低于 `D` 级；
  - 工作温度 `≤ -20 ℃`：Q235、Q345 不应低于 `D` 级，Q390~Q460 应选用 `E` 级。
- **无加劲直接焊接相贯钢管节点（4.3.7）**：管材屈强比不宜大于 `0.8`；受拉焊接钢管壁厚 `> 25 mm` 时应采取防层状撕裂措施。

## 钢材与结构用无缝钢管强度设计指标（表4.4.1 / 表4.4.3，单位：N/mm²）

- **Q235（壁厚/板厚 `≤ 16 mm`）**：抗拉/抗压/抗弯 `f = 215`，抗剪 `fv = 125`，端面承压 `fce = 320`，屈服强度 `fy = 235`，抗拉强度 `fu = 370`（无缝管 `375`）。
- **Q345（壁厚/板厚 `≤ 16 mm`）**：抗拉/抗压/抗弯 `f = 305`，抗剪 `fv = 175`，端面承压 `fce = 400`，屈服强度 `fy = 345`，抗拉强度 `fu = 470`。
- **Q345（`16 mm < t ≤ 40 mm`，板材）**：`f = 295`，`fv = 170`，`fy = 335`；无缝管 `16 mm < t ≤ 30 mm`：`f = 290`，`fv = 170`，`fy = 325`。
- **Q390（`t ≤ 16 mm`）**：`f = 345`，`fv = 200`，`fy = 390`，`fu = 490`。
- **注**：冷弯型材和冷弯钢管的强度设计值应按现行冷弯薄壁型钢相关标准采用（表 4.4.1 注 2）。

## 焊缝与螺栓强度设计值摘要（表4.4.5 / 表4.4.6，单位：N/mm²）

- **Q345（`t ≤ 16 mm`，自动焊/半自动焊/E50 型焊条）**：
  - 对接焊缝：抗压 `f_c^w = 305`；一、二级抗拉 `f_t^w = 305`，三级抗拉 `260`；抗剪 `f_v^w = 175`；
  - 角焊缝强度设计值：`f_f^w = 200`（E50 焊条）。
- **承压型高强螺栓**：`8.8` 级抗拉 `400`、抗剪 `250`；`10.9` 级抗拉 `500`、抗剪 `310`。
- **无垫板单面施焊对接焊缝折减（4.4.5）**：乘以折减系数 `0.85`；高空施工条件较差安装焊缝乘以 `0.9`。

## 钢材物理性能指标（表4.4.8）

- 弹性模量 \(E = 206 \times 10^3\text{ N/mm}^2\)
- 剪变模量 \(G = 79 \times 10^3\text{ N/mm}^2\)
- 线膨胀系数 \(\alpha = 12 \times 10^{-6}\text{ /℃}\)
- 质量密度 \(\rho = 7850\text{ kg/m}^3\)
