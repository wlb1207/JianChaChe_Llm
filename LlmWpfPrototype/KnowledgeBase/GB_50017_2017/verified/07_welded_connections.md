# 钢结构焊缝连接计算、质量等级与构造要求

Source: GB 50017-2017
Topic: 焊缝质量等级、角焊缝与对接焊缝计算及构造
SourceType: rule
Verified: true
Clause: 11.1, 11.2, 11.3, 表11.3.5
Page: 标准正文第107-116页

## 适用范围

本知识块依据 GB 50017—2017 第 11.1~11.3 节，规定钢结构焊接连接布置原则、焊缝质量等级、对接与角焊缝强度计算公式以及动载焊接构造红线。

## 焊缝布置与质量等级选用（11.1.5, 11.1.6）

- 布置原则：尽量减少焊缝数量与尺寸、对称于截面形心轴、留足施焊与检测空间、避免焊缝密集及双向/三向相交、避开最大应力区、异种钢匹配低强度钢材焊材。
- **承受动荷载且需疲劳验算的等强焊缝（11.1.6-1）**：横向对接或 T 形组合焊缝**受拉应为一级、受压不应低于二级**；纵向对接焊缝不应低于二级。
- 工作温度 `≤ -20 ℃` 地区，构件对接焊缝质量不得低于二级（11.1.6-2）。
- 同一连接部位不得采用普通螺栓或承压型高强螺栓与焊接共用连接（11.1.2）。

## 焊缝强度计算（11.2.1, 11.2.2, 11.2.6）

- **全熔透对接焊缝**：正应力 \(\sigma = N / (l_w h_e) \le f_t^w\) 或 \(f_c^w\)；弯剪共同作用折算应力 \(\sqrt{\sigma^2 + 3\tau^2} \le 1.1 f_t^w\)。
- **直角角焊缝**：计算厚度 \(h_e = 0.7 h_f\)（间隙 `≤ 1.5 mm`），计算长度 \(l_w\) 扣除 \(2 h_f\)；综合受力验算：
\[
\sqrt{\left(\frac{\sigma_f}{\beta_f}\right)^2 + \tau_f^2} \le f_f^w
\]
其中正面角焊缝增大系数 \(\beta_f\)：静载及间接动载取 **`1.22`**，**直接承受动力荷载取 `1.0`**。
- 搭接角焊缝计算长度 \(l_w > 60 h_f\) 时须乘折减系数 \(\alpha_f = 1.5 - l_w / (120 h_f)\) 且不小于 `0.5`（11.2.6）。

## 角焊缝尺寸与动载焊接构造边界（11.3.4, 11.3.5, 11.3.6）

- **最小焊脚尺寸（表11.3.5）**：
  - 母材厚度 `t ≤ 6 mm`：最小焊脚尺寸 `hf = 3 mm`；
  - `6 mm < t ≤ 12 mm`：`hf = 5 mm`；
  - `12 mm < t ≤ 20 mm`：`hf = 6 mm`；
  - `t > 20 mm`：`hf = 8 mm`。
- 角焊缝最小计算长度：`≥ 8 hf` 且 `≥ 40 mm`（11.3.5-1）。
- 搭接焊缝沿母材棱边最大焊脚尺寸：`t ≤ 6 mm` 时取 `t`，`t > 6 mm` 时取 `t - (1~2) mm`（11.3.6-4）。
- **承受动荷载焊接构造禁令（11.3.4）**：
  - 不得采用焊脚尺寸小于 **`5 mm`** 的角焊缝；
  - **严禁采用断续坡口焊缝和断续角焊缝**（腐蚀环境中也不宜采用断续角焊缝，11.3.8）；
  - 需疲劳验算且拉应力垂直焊缝轴线时，严禁采用部分焊透对接焊缝；
  - 不同厚度/宽度对接应平缓过渡，坡度不宜大于 `1:2.5`（疲劳构件最大 `1:4`）。
