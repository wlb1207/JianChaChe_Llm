## 适用范围

本知识块依据《结构用冷弯型钢》（GB/T 6728—2025）第 6.1.1、6.2.1、6.3.1、6.4 节及附录 A、附录 B，规定方形与矩形冷弯闭口型钢的几何公差边界、交货长度重量规则及非标尺寸计算方法。

## 弯角外圆弧半径 R（或 C1、C2）规定（6.1.1.6, 表4）

闭口型钢的弯角外圆弧半径 `R`（或弯角区域长度 `C_1、C_2`）按图 4 或圆角规测量，产生争议时以外圆弧半径 `R` 值为准：

| 公称壁厚 t（mm） | 碳素钢（R_eH ≤ 320 MPa） | 低合金钢（R_eH > 320 MPa，如 Q355B） |
|---|---|---|
| `t ≤ 3` | `(1.0 ~ 2.5)t` | `(1.5 ~ 2.5)t` |
| `3 < t ≤ 6` | `(1.5 ~ 2.5)t` | **`(2.0 ~ 3.0)t`** |
| `6 < t ≤ 10` | `(2.0 ~ 3.0)t` | `(2.0 ~ 3.5)t` |
| `t > 10` | `(2.0 ~ 3.5)t` | `(2.5 ~ 4.0)t` |

- **对本车宽厚比与焊缝节点的影响**：本车 `Q355B` 方管（`R_eH = 355 MPa > 320 MPa`，壁厚 `4 ~ 5 mm`）外圆弧半径允许范围为 `(2.0 ~ 3.0)t`（即 `t = 5 mm` 时 `R = 10 ~ 15 mm`，`t = 4 mm` 时 `R = 8 ~ 12 mm`）。外圆弧越大，方管平面段净宽 `b_0` 越小，同时腹杆/横管支管与主弦杆弯角区相贯焊缝间隙与坡口组装要求需同步复核。

## 型钢壁厚允许偏差与仲裁测量位置（6.1.1.5, 附录B 表B.1, B.2）

型钢壁厚仲裁时在距离端部 `50 mm` 处测量；对方形或矩形型钢，在同一截面避开弯角及焊缝选取 `5` 处测量并取平均值（其中焊缝热影响区测点距离焊缝约 `2t`，最大 `40 mm`、最小 `5 mm`），平均值与公称壁厚偏差满足表 B.1 即为合格：

| 公称壁厚区间（mm） | 壁厚允许偏差（mm） |
|---|---:|
| `>1.50 ~ 2.00` | `±0.23` |
| `>2.00 ~ 2.50` | `±0.28` |
| `>2.50 ~ 3.00` | `±0.29` |
| **`>3.00 ~ 4.00`** | **`±0.30`** |
| **`>4.00 ~ 5.00`** | **`±0.32`** |
| **`>5.00 ~ 6.00`** | **`±0.34`** |
| `>6.00 ~ 8.00` | `±0.39` |
| `>8.00 ~ 10.00` | `±0.44` |
| `>10.00 ~ 12.50` | `±0.47` |
| `>12.50 ~ 15.00` | `±0.51` |
| `>15.00 ~ 18.00` | `±0.55` |
| `>18.00 ~ 25.00` | `±1.10` |

- **负偏差防腐叠加提示**：例如公称 `4.0 mm` 方管允许负偏差 `-0.30 mm`（实测下限 `3.70 mm`），`5.0 mm` 方管允许 `-0.32 mm`（实测下限 `4.68 mm`）；结合 `GB/T 3811—2008` 表 34 中等腐蚀环境闭口截面最小壁厚 `4 mm`，选材与入厂检验时须关注负偏差与锈蚀裕量。

## 外形、定尺长度、测量位置与重量偏差（6.1.1.7-6.1.1.9, 6.2.1, 6.3.1, 6.4）

- **平面凸凹度（6.1.1.7）**：截面平面部分凸凹度 `X_1、X_2` 不超过该边长的 `0.6%`，最小值为 `0.4 mm`。
- **弯曲角度偏差（6.1.1.8）**：方形或矩形闭口型钢弯曲角度 `θ` 的偏差不应大于 `±1.5°`。
- **尺寸测量位置（6.1.1.9, 表5）**：`H(B) ≤ 100 mm` 时距端部不小于 `200 mm`；`100 < H(B) ≤ 300 mm` 时距端部不小于 `300 mm`；`300 < H(B) ≤ 500 mm` 时不小于 `400 mm`。
- **交货长度与定尺偏差（6.2.1, 表21）**：闭口型钢通常长度 `4000 ~ 12000 mm`，**不准许对接交货**；短尺及非定尺长度不小于 `2000 mm` 且占比 `≤ 5%`（理论重量 `> 20 kg/m` 时 `≤ 10%`）。
  - 普通定尺（`4000 ~ 12000 mm`）：`+50 / 0 mm`；
  - 精确定尺（`4000 ~ 6000 mm`）：`+5 / 0 mm`；（`> 6000 ~ 12000 mm`）：`+10 / 0 mm`。
- **弯曲度、扭转度与锯切斜度（6.3.1, 表23）**：
  - 弯曲度：每米不应大于 `2 mm`，总弯曲度不应大于总长度的 `0.15%`；
  - 扭转度（协商测量，式 1）：\(V = 2 + L \times 0.5 / 1000\)（单位 `mm`，`L` 为长度 `mm`）；
  - 锯切斜度（表 23）：最大公称边长 `≤ 100 mm` 应 `< 2 mm`，`> 100 ~ 300 mm` 应 `< 4 mm`，`> 300 ~ 500 mm` 应 `< 6 mm`。
- **重量允许偏差（6.4）**：按实际重量交货；经协商按理论重量交货时，型钢边长合计 `≤ 1600 mm` 每批允许偏差为 **`-6% ~ +10%`**，超过 `1600 mm` 为 **`-4% ~ +6%`**。

## 方形、矩形闭口型钢截面特性计算公式（附录A 表A.2）

对表 1、表 2 未列出的其他尺寸和壁厚，公称截面特性可按表 A.2 计算（边长 `H、B` 与壁厚 `t` 单位为 `mm`）：

- **公称圆弧半径**：`t ≤ 6 mm` 取 \(R = 2.0t\)；`6 mm < t ≤ 10 mm` 取 \(R = 2.5t\)；`t > 10 mm` 取 \(R = 3.0t\)；内圆弧半径 \(r = R - t\)。
- **截面面积与理论重量**：
  $$A = \frac{2t(B + H - 2t) - (4 - \pi)(R^2 - r^2)}{10^2}\;(\text{cm}^2),\quad M = 0.785A\;(\text{kg/m})$$
- **每米长度表面积**：
  $$A_s = 2(H + B - 4R + \pi R) \times 10^3\;(\text{mm}^2/\text{m})$$
- **惯性矩、惯性半径与弹性截面模数**：
  $$I_x = \frac{1}{10^4}\left[\frac{BH^3}{12} - \frac{(B-2t)(H-2t)^3}{12} - 4(I_z + A_z h_z^2) + 4(I_s + A_s' h_s^2)\right]\;(\text{cm}^4)$$
  其中外圆弧角部项 \(I_z = \left[\frac{1}{3} - \frac{\pi}{16} - \frac{1}{3(12-3\pi)}\right]R^4\)，\(A_z = (1 - \frac{\pi}{4})R^2\)，\(h_z = \frac{H}{2} - \frac{10-3\pi}{12-3\pi}R\)；内圆弧角部项 \(I_s, A_s', h_s\) 将上述各式中的 `R` 替换为 `r`、`H` 替换为 `H - 2t`；求 `I_y` 时互换 `B` 与 `H`。
  $$r_x = \sqrt{\frac{I_x}{A}},\quad r_y = \sqrt{\frac{I_y}{A}},\quad W_x = \frac{2I_x}{H}\times 10,\quad W_y = \frac{2I_y}{B}\times 10$$
- **扭转常数与扭转模数**：
  $$I_t = \frac{1}{10^4}\left(\frac{t^3 h}{3} + 2K A_h\right),\quad C_t = 10\frac{I_t}{t + K/t}$$
  其中 \(R_c = \frac{R+r}{2}\)，\(h = 2[(B-t)+(H-t)] - 2R_c(4-\pi)\)，\(A_h = (B-t)(H-t) - R_c^2(4-\pi)\)，\(K = \frac{2A_h t}{h}\)。
